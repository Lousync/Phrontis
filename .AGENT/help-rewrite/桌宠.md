# 桌宠

**桌宠**是工作台右栏里的养成小控件，在 Phrontis 中**自成一类**：它不属于任何模块，也没有独立窗口。用户可对其喂食、摸摸头、改名、切换品种。宠物按真实流逝时间变饿、变蔫，但**不会死亡**。数据存放在仓库文件夹内的 `.knowbase/modules/pet/pet.json`，随仓库一起备份与迁移；桌宠完全离线，不联网、不影响其它模块。

## 桌宠在哪打开

打开路径：**工作台 → 右栏 → 🧩 小工具 Tab → 底部控件切换条 → 点「桌宠」图标**。

右栏默认收起，把鼠标移到窗口右边缘出现的 6px 手柄上单击即可展开。右栏顶部是图标形式的 Tab 头（🧩 小工具 / 🤖 AI），点击切到「小工具」态。控件切换条位于右栏下段，点其中的「桌宠」即显示。切换条右侧的 ⋯ 按钮打开「显示的小控件」菜单，可勾选显隐并拖拽排序。未打开仓库时，桌宠显示空态提示「打开一个仓库后，桌宠才会住进来」。

## 怎么喂食和摸摸头

桌宠控件顶部工具条有两个互动按钮；**直接点击立绘**与「摸摸头」是同一操作。

- **🍎 喂食**：提升饱食与心情，并增加成长值。
- **✋ 摸摸头**：提升心情，并增加少量成长值，飘出爱心。
- **⋯ 菜单**：切换宠物 / 改名 / 重新养一只。

**吃饱后宠物会拒绝进食**（饱食接近满值时），气泡提示「吃不下了」，此时不增加任何数值。喂食与摸摸头均**免费**：没有消耗、没有次数限制、没有货币系统。瞬时动作播放期间（吃饭、害羞、跳跃、拒绝）不会重复触发。

## 三条状态条是什么意思

- **饱食**：随时间下降，喂食回升。饱食偏低时立绘切到饥饿姿态，并偶发讨食气泡。
- **心情**：随时间下降，摸摸头回升。心情偏低时立绘改为趴下姿态，并偶发无聊气泡。
- **成长**：只在**幼年**阶段显示；成年后该行消失，成长数值位置改显示「满成长」。

立绘旁的标签显示当前名字、「幼年」或「成年」徽标与成长进度。控件末行显示当前**活跃度**百分比。

## 宠物怎么长大、什么时候成年

成长值攒满即由「幼年」进化为「成年」：立绘切换为更成熟的形态，播放跳跃动画与「我长大啦！」气泡。成长值来自喂食与摸摸头，**活跃度越高单次获得越多**。成年后成长值不再增长，界面显示「满成长」。成年**不可逆**，不会退回幼年。

## 宠物饿了、心情低会怎样

衰减在主进程按**真实流逝时间**结算——宠物在你没打开软件时同样会变饿，不是在打开那一刻才开始掉。饱食随时间下降；心情也随时间下降，且**饱食越低心情掉得越快**。长时间不开软件不会一次性掉到谷底。

**饥饿与心情不设惩罚**：宠物不会死亡、不会消失、不会降低任何数值上限，只是立绘变蔫并出现抱怨气泡。**夜间 23:00 至次日 7:00** 立绘自动进入睡眠姿态并显示「Z」气泡。喂食与摸摸头随时可用，不受时段限制。

## 活跃度是什么

活跃度由**当日使用数据**实时计算，共四项输入：**使用软件时长、打卡连续天数、当日笔记产出、当日 AI 互动次数**（使用时长占比最高，AI 互动占比最低）。它不落盘，每次打开控件现算。作用有两条：**活跃度越高，心情衰减越慢**；**活跃度越高，喂食与摸摸头获得的成长值越多**。活跃度不影响饱食，也不折算成任何奖励。

## 怎么换宠物、改名、重新养一只

点击控件右上角的 **⋯** 按钮打开宠物菜单：

- **切换宠物**：在小狗 / 小猫 / 小克苏恩等**内置品种**间切换，后续还会扩充更多品种。切换**只换皮肤，全部进度保留**——名字、阶段、成长值、饱食、心情一律不动。
- **改名**：名字上限 **8 个字**。名字**跟着品种各记各的**：每个品种保存自己的名字，切换品种不会互相覆盖。
- **重新养一只**：数值重置为初始状态（幼年、饱食与心情回到初始值），并把**当前品种**的名字恢复为默认名；**其它品种的名字不受影响**。

## 宠物数据存在哪

桌宠状态存放在仓库文件夹内的 `.knowbase/modules/pet/pet.json`，这是唯一真相源。**整个仓库文件夹拷走 = 连同桌宠一起备份**，拷回来即恢复；换电脑或重装软件后数值照旧。删除该文件等于让桌宠回到初始状态。桌宠不写数据库、不上云、不需要账号。

## 桌宠不支持什么

- 不支持**多窗口或桌面悬浮式桌宠**，它只存在于工作台右栏。
- **没有死亡、没有养成任务、没有货币与商店**，喂食永远免费。
- 不联网，不消耗任何在线服务。
- 品种目前均为内置品种，**由插件扩充品种的能力尚未开放**。
