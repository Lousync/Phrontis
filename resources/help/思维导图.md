# 思维导图

思维导图是 AI 教学与笔记区**共用**的结构化图：AI 一句话生成，可折叠、缩放、直接编辑，能**导出成知识库笔记**，也能被笔记正文的 `[[双链]]` 指向、出现在知识图谱里。

## 生成（/mindmap）

在 **AI 教学**输入框输入斜杠指令 **`/mindmap`**，后面可跟主题或要求（例：`/mindmap 把刚讲的二叉树遍历整理一下`）；不填则默认整理**当前对话**。AI 只把结构交给工具生成，产物落进右栏「**工件栏**」，作为一个「思维导图」页签打开（对话流里同时出现对应的工件卡）。内容来源可以是当前对话、会话已登记的素材，或你在指令里点名的知识库笔记。

## 查看与编辑

- **折叠 / 展开**：点带子节点的节点即折叠或展开；工具条「全部展开 / 全部折叠」一键处理。
- **缩放 / 平移**：滚轮缩放、空白处拖拽平移；「适应画布」一键复位。
- **改字**：双击节点改文字。
- **增删**：悬停节点出现 `＋`（加子节点）与 `×`（删除）。
- **重挂 / 排序**：拖动节点到目标节点上（成为其子节点）、或到其上 / 下缘（插到前面 / 后面）。
- **撤销 / 重做**：Ctrl+Z / Ctrl+Y。

编辑**自动保存**到会话文件夹里的导图 JSON，无需手动保存。

## 导出为知识库笔记

工具条「**导出为笔记**」→ 行内选分类 → 确认。新笔记正文同时含**多级大纲列表**与一段 **Mermaid `mindmap` 代码块**，后者在笔记里直接渲染成一张**静态图**（是导出那一刻的快照）。

## 在笔记区打开导图

被打开的 `.json` 文件若内容是思维导图（含判别字段），笔记区会**按内容识别**并渲染成交互导图，而不是当普通文本。页头可切「**查看 / 编辑 JSON 源码**」，手改 JSON 后点「**保存并重新渲染**」——**必须保留导图判别字段**，否则下次打开不再识别为导图。

## 双链与知识图谱

- 笔记正文写 `[[导图标题]]` 可解析并打开对应导图（标题取自导图 JSON 的 `title`）。
- 导图里带**引用（ref）**的节点可指向另一张导图或一篇笔记，点击即打开：在 AI 教学里**在右栏工件栏新开页签**（不切换模块），在笔记区里**同模块开页签**。
- 导图会作为节点出现在**知识图谱**里，与引用它的笔记相连。

## 不支持什么

导图是**会话产物（JSON）**，不带知识库身份，**不出现在知识库目录树**；要让它在知识库里出现，请「导出为笔记」。不做自由布局（节点位置由层级自动排布）。树过深或节点过多会由工具侧截断并在结果里说明。
