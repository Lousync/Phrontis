# 笔记 · 双链与关联网络

在笔记正文里写 `[[另一篇的标题]]` 即建立一条指向它的**双链**；编辑器右栏的「**关联网络**」把本页与其他页的链接关系列出来，点条目可**定位到正文里那条链接处并高亮**。

## 双链写法（[[ ]]）

在中栏编辑页签的正文里输入 `[[` 会弹出候选（按标题匹配仓库内笔记），选中即补全。渲染后点这条链接会打开对应笔记；标题写错或没有对应笔记时，会提示「未找到『X』」并引导你去「新建知识页」建这一页——**不会自动建页**。双链也会让两篇笔记在**知识图谱**里相连。

## 关联网络面板

笔记编辑器右栏的「关联网络」分两部分：

- **引用（出链）**：本页正文里出现的所有 `[[链接]]`（按标题解析）。点其中一条 → 正文**滚动到对应链接处并高亮**，你再点正文里的链接即可跳转。
- **被引用（反链）**：有哪些**其它页面**引用了本页。点其中一条 → **跳到那篇源页**，并把源页里引用本页的位置**滚动到并高亮**。

早期版本里还有一个「相关笔记」清单，**现已移除**。

## 在正文末尾直接看反向链接

不想开右栏时，可以在**阅读态**点顶栏 `⋮` 里的「**在标签页中显示反向链接**」（括号里是条数）：正文末尾会多出一节「反向链接」，逐条列出**谁引用了本页**，并带上那一处在源页里的**上下文摘录**；点一条和右栏「被引用」一样 —— 跳到源页并把引用处滚到眼前、闪一下高亮。这是**本页临时**开关，换一篇就复位，不写进文件也不改设置；**源码档下不出现**（那里写作面占满整块，没地方放它），要看就先用 `Ctrl+E` 切到阅读态。

## 高亮与定位

「引用 / 被引用」两处跳转都会**滚动到正文对应位置并闪一下高亮**，便于在长文里一眼找到那条链接；高亮是临时的，不写入文件。

## 知识图谱

知识图谱是笔记链接的可视化，入口在笔记模块内；它是一个**独立页签**，关闭后需要从笔记模块内重新进入。双链与导图引用都会反映到图谱的节点连线上。
