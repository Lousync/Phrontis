## 全局

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `Shift` `P` | 命令面板（按功能名或模块名搜索直达） |
| `Ctrl` `O` | 快速打开文件（按标题 / 路径搜仓库页面，回车即打开） |
| `Ctrl` `P` | 全局搜索（左栏搜索态：标题、正文、目录、标签）；`Ctrl` + 反引号、`Ctrl` `Shift` `F` 同效 |
| `Ctrl` `J` | 工作台内唤出 / 收起右栏 AI 侧栏（整窗模块内归 AI 侧栏自己接管） |
| `Ctrl` `B` | 折叠 / 展开侧栏 |
| `Escape` | 关闭弹窗 / 返回列表 |

工作台中间**没有打开任何页签时显示空态**（启动首屏即是，关掉最后一个模块标签也回到这里），空态里固定摆着其中三条：打开命令面板、快速打开文件、AI 助手。点击任一条与按对应快捷键等效。在笔记模块里关掉最后一个**页面**不会退出模块，中间显示的是笔记模块自己的空态（无这三条），点其中的「回工作台」回到这里。

## 编辑器内（写作面）

焦点在知识库笔记的编辑区里时生效；两个写作模式档位（源码 / 即时渲染）键位一致。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `B` | 加粗（编辑器内是加粗，不是折叠侧栏） |
| `Ctrl` `I` | 斜体 |
| `Ctrl` `K` | 新增外部链接 |
| `Ctrl` `Alt` `1` / `2` / `3` | 标题 1 / 标题 2 / 标题 3 |
| `Ctrl` `Alt` `0` | 正文 |
| `Ctrl` `Shift` `I` | 插图（编辑器内；按钮收进顶栏 ⋮ 菜单后，这是键盘入口） |
| `Ctrl` `Alt` `F` | 插入脚注（要求先选中单行文字） |
| `Ctrl` `F` | 查找（源码档是 Monaco 查找框，即时渲染档是内置查找面板；`Ctrl` `G` / `F3` 下一个、`Esc` 关闭） |
| `Ctrl` `E` / `Ctrl` `/` | 阅读 ⇄ 编辑切换（与「切换 Markdown 预览」是同一个动作） |
| `Alt` `A` | 立即要一条 AI 内联续写建议（只在源码档） |

## 笔记顶栏（页面历史）

知识库每个页面顶部都有一行顶栏：左段是页面历史的前进 / 后退按钮，中段是文件名与保存点，右段是 AI 续写、阅读切换与 `⋮` 菜单。Markdown 笔记的 `⋮` 里收着插图、脚注、文件格式、收藏、沉浸阅读等；非 Markdown 文件（PDF / 代码 / 文本 / HTML / 图片）用的是**同一条顶栏**，但右端通常只剩 `⋮`（文件信息 / 在系统中打开 / 在文件夹中显示 / 复制相对路径；HTML 与 SVG 多一项「看源码」，图片多一组「查看」）。思维导图除外（它自带工具条）。分屏时主栏与副栏各挂各的顶栏。

| 快捷键 | 功能 |
|--------|------|
| `Alt` `←` | 后退到上一个页面（历史里已失效的页面自动跳过） |
| `Alt` `→` | 前进到下一个页面 |
| `Ctrl` `Shift` `R` | 进入 / 退出沉浸阅读（作用于主栏的当前页面） |

历史是**全局单条**的（后退后再点开新页面，前进分支会被截断），最多记 50 条，不落盘、重启清空。在编辑器里按也生效。

## 图片查看器

在笔记区打开仓库里的图片（`png` / `jpg` / `jpeg` / `webp` / `gif` / `bmp` / `svg` / `avif`）时生效，四个键**都不带修饰键**：

| 快捷键 | 功能 |
|--------|------|
| `0` | 适应窗口（比窗口小的图不放大） |
| `1` | 实际大小 1:1 |
| `[` | 向左旋转 90° |
| `]` | 向右旋转 90° |

`Ctrl` + 滚轮以**光标为锚点**缩放，拖拽平移，双击在「适应窗口 ⇄ 100%」之间切换。焦点在输入框里时这四个键不生效。

## 知识库

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `N` | 新建知识页（文件树内联命名，落点跟随选中目录） |
| `Ctrl` `W` | 关闭当前 Tab |
| `Ctrl` `Tab` | 下一个 Tab |
| `Ctrl` `Shift` `Tab` | 上一个 Tab |
| `F2` | 重命名选中项 |
| `Delete` | 删除选中项（页面 > 章节 > 目录） |
| `Ctrl` `S` | 立即保存 |
| `Ctrl` `/` | 切换 Markdown 预览 |

**页面分屏没有快捷键**，入口在页面标签的右键菜单（向右拆分 / 向下拆分），详见《工作台页面分屏》。

## 博客

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `N` | 新建 / 打开今日文章 |
| `Ctrl` `S` | 保存并关闭 |
| `Ctrl` `/` | 切换预览 |
| `Ctrl` `Alt` `O` | 切换大纲（编辑器 / 详情态） |
| `Escape` | 返回列表 |
| `Delete` | 删除文章 |

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `N` | 新建任务 |
| `Escape` | 关闭弹窗 |

## 日程与打卡小窗

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `Alt` `S` | 打开 / 关闭小窗(全局生效) |
| `Escape` | 关闭小窗(输入框有焦点时先退出输入) |
