## 全局

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `B` | 折叠 / 展开侧栏 |
| `Escape` | 关闭弹窗 / 返回列表 |

## 编辑器

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `N` | 新建文件（根目录内联命名，含知识页草稿） |
| `Ctrl` `S` | 保存当前文件 |
| `Ctrl` `Shift` `S` | 保存全部 |

## 编辑器内（写作面）

焦点在知识库笔记的编辑区里时生效；两个写作模式档位（源码 / 即时渲染）键位一致。

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `B` | 加粗（编辑器内是加粗，不是折叠侧栏） |
| `Ctrl` `I` | 斜体 |
| `Ctrl` `K` | 新增外部链接 |
| `Ctrl` `Alt` `1` / `2` / `3` | 标题 1 / 标题 2 / 标题 3 |
| `Ctrl` `Alt` `0` | 正文 |

## 知识库

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `N` | 新建知识页（跳转编辑器进入命名） |
| `Ctrl` `W` | 关闭当前 Tab |
| `Ctrl` `Tab` | 下一个 Tab |
| `Ctrl` `Shift` `Tab` | 上一个 Tab |
| `F2` | 重命名选中项 |
| `Delete` | 删除选中项（页面 > 章节 > 目录） |
| `Ctrl` `S` | 立即保存 |
| `Ctrl` `/` | 切换 Markdown 预览 |

## 博客

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `N` | 新建 / 打开今日文章 |
| `Ctrl` `S` | 保存并关闭 |
| `Ctrl` `/` | 切换预览 |
| `Escape` | 返回列表 |
| `Delete` | 删除文章 |

## 日程

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `N` | 新建任务 |
| `Escape` | 关闭弹窗 |

## 日程与打卡小窗

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `Alt` `S` | 打开 / 关闭小窗(全局生效) |
| `Escape` | 关闭小窗(输入框有焦点时先退出输入) |
