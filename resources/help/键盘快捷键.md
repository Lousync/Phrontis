# 键盘快捷键

全局键位、笔记写作面与顶栏侧栏、图片查看器、电子书阅读器、博客、日程与打卡小窗、密码本 —— 每一节先说明**在什么状态下生效**，再列键位。

## 全局

<!-- GEN:keytable ids=palette,quick-open,global-search,ai-side,ai-full,sidebar,right-panel,undo,redo,zoom-in,zoom-out,escape -->
| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `Shift` `P` | 命令面板 |
| `Ctrl` `O` | 快速打开文件（按标题 / 路径搜仓库页面） |
| `Ctrl` `P` / `Ctrl` 反引号 / `Ctrl` `Shift` `F` | 全局搜索（左栏搜索态：标题、正文、目录、标签） |
| `Ctrl` `J` | AI 助手开关（工作台右栏；整窗模块下为悬浮助手） |
| `Ctrl` `Shift` `J` | AI 助手：进入全屏学堂 |
| `Ctrl` `B` | 展开 / 折叠侧栏 |
| `Ctrl` `Alt` `B` | 切换工作台右栏（折叠 / 展开） |
| `Ctrl` `Z` | 撤销上一文件操作（重命名 / 删除 / 移动） |
| `Ctrl` `Shift` `Z` / `Ctrl` `Y` | 重做文件操作 |
| `Ctrl` `=` | 界面放大 |
| `Ctrl` `-` | 界面缩小 |
| `Escape` | 关闭弹窗 / 返回列表 |
<!-- /GEN -->

工作台中间**没有打开任何页签时显示空态**（启动首屏即是，关掉最后一个模块标签也回到这里），空态里固定摆着其中三条：打开命令面板、快速打开文件、AI 助手。点击任一条与按对应快捷键等效。在笔记模块里关掉最后一个**页面**不会退出模块，中间显示的是笔记模块自己的空态（无这三条），点其中的「回工作台」回到这里。

## 编辑器内（写作面）

焦点在知识库笔记的编辑区里时生效；两个写作模式档位（源码 / 即时渲染）键位一致。

<!-- GEN:keytable ids=ed-bold,ed-italic,ed-link,ed-h1,ed-h2,ed-h3,ed-p,ed-find,kb-preview,kb-image,kb-footnote,kb-ai-inline -->
| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `B` | 加粗（编辑器内是加粗，不是折叠侧栏） |
| `Ctrl` `I` | 斜体 |
| `Ctrl` `K` | 新增外部链接 |
| `Ctrl` `Alt` `1` | 标题 1 |
| `Ctrl` `Alt` `2` | 标题 2 |
| `Ctrl` `Alt` `3` | 标题 3 |
| `Ctrl` `Alt` `0` | 正文（取消标题） |
| `Ctrl` `F` | 查找（源码档是 Monaco 查找框，即时渲染档是内置查找面板；Ctrl+G / F3 下一个、Esc 关闭） |
| `Ctrl` `/` / `Ctrl` `E` | 阅读 ⇄ 编辑切换（仅 md / txt 文件） |
| `Ctrl` `Shift` `I` | 插入图片（顶栏 ⋮ 里也有） |
| `Ctrl` `Alt` `F` | 插入脚注（先选中词语；顶栏 ⋮ 里也有） |
| `Alt` `A` | AI 内联续写建议：立即要一条（Tab 采纳 / Esc 拒绝；平时停顿会自动出） |
<!-- /GEN -->

## 笔记顶栏（页面历史）

知识库每个页面顶部都有一行顶栏：左段是页面历史的前进 / 后退按钮，中段是文件名与保存点，右段是 AI 续写、阅读切换与 `⋮` 菜单。Markdown 笔记的 `⋮` 里收着插图、脚注、文件格式、收藏、沉浸阅读等；非 Markdown 文件（PDF / 代码 / 文本 / HTML / 图片）用的是**同一条顶栏**，但右端通常只剩 `⋮`（文件信息 / 在系统中打开 / 在文件夹中显示 / 复制相对路径；HTML 与 SVG 多一项「看源码」，图片多一组「查看」）。思维导图除外（它自带工具条）。分屏时主栏与副栏各挂各的顶栏。

<!-- GEN:keytable ids=kb-back,kb-fwd,kb-immersive,kb-immersive-esc -->
| 快捷键 | 功能 |
|--------|------|
| `Alt` `←` | 页面历史：后退（笔记区顶栏最左那颗箭头） |
| `Alt` `→` | 页面历史：前进 |
| `Ctrl` `Shift` `R` | 沉浸阅读进出 |
| `Escape` | 沉浸阅读退出 |
<!-- /GEN -->

历史是**全局单条**的（后退后再点开新页面，前进分支会被截断），最多记 50 条，不落盘、重启清空。在编辑器里按也生效。

## 图片查看器

在笔记区打开仓库里的图片（`png` / `jpg` / `jpeg` / `webp` / `gif` / `bmp` / `svg` / `avif`）时生效，四个键**都不带修饰键**：

<!-- GEN:keytable ids=img-fit,img-actual,img-rotl,img-rotr -->
| 快捷键 | 功能 |
|--------|------|
| `0` | 适应窗口（比窗口小的图不放大） |
| `1` | 实际大小 1:1 |
| `[` | 向左旋转 90° |
| `]` | 向右旋转 90° |
<!-- /GEN -->

`Ctrl` + 滚轮以**光标为锚点**缩放，拖拽平移，双击在「适应窗口 ⇄ 100%」之间切换。焦点在输入框里时这四个键不生效。

## 知识库

<!-- GEN:keytable ids=kb-save,kb-new,kb-close-tab,kb-next-tab,kb-prev-tab,kb-editor-esc,sb-rename,sb-delete,sb-copy,sb-cut,sb-paste -->
| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `S` | 立即保存当前页面 |
| `Ctrl` `N` | 新建知识页（文件树内联命名，落点跟随选中目录） |
| `Ctrl` `W` | 关闭当前打开的 Tab 页 |
| `Ctrl` `Tab` | 切换到下一个 Tab |
| `Ctrl` `Shift` `Tab` | 切换到上一个 Tab |
| `Escape` | 关闭弹窗后返回页面列表 |
| `F2` | 重命名选中的目录 / 笔记本 / 章节 |
| `Delete` | 删除选中的目录 / 笔记本 / 章节 |
| `Ctrl` `C` | 复制选中的页面 / 目录到内部剪贴板（非输入框时） |
| `Ctrl` `X` | 剪切选中的页面 / 目录（非输入框时） |
| `Ctrl` `V` | 粘贴内部剪贴板到选中目标（非输入框时） |
<!-- /GEN -->

**页面分屏没有快捷键**，入口在页面标签的右键菜单（向右拆分 / 向下拆分），详见《工作台页面分屏》。

## 电子书阅读器

在笔记区打开仓库里的 PDF 或电子书（EPUB）时生效。翻页那几枚键（`PageUp` / `PageDown` / `空格`、以及 `←` / `→`）**两个阅读器都吃**；电子书阅读器不接受带修饰键的组合，所以页内搜索与页面缩放只对 PDF 生效。

<!-- GEN:keytable ids=pdf-find,pdf-next,pdf-prev,pdf-zoom-in,pdf-zoom-out,pdf-zoom-fit -->
| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `F` | PDF 阅读器内搜索 |
| `PageDown` / `空格` / `→` | PDF 下一页 |
| `PageUp` / `←` | PDF 上一页 |
| `Ctrl` `=` | PDF 放大 |
| `Ctrl` `-` | PDF 缩小 |
| `Ctrl` `0` | PDF 适应窗口 |
<!-- /GEN -->

## 日程与打卡小窗

<!-- GEN:keytable ids=sys-day,sys-dock,sys-widget -->
| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `Alt` `S` | 日程与打卡小窗开关（系统级） |
| `Ctrl` `Alt` `Up` | 日程侧栏置顶停靠（系统级） |
| `Ctrl` `Alt` `Down` | 日程侧栏切为桌面小组件（系统级） |
<!-- /GEN -->

小窗是系统级窗口，`Escape` 走的就是全局那条：输入框有焦点时先退出输入，再按一次才关窗。

## 密码本

密码填充是**系统级**弹窗开关（在任意程序里都生效）。改键目前只能手改 `settings.json` 的 `fillPopupShortcut` —— 设置页没有这一项。

<!-- GEN:keytable ids=sys-pwdfill -->
| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `Alt` `P` | 密码填充弹窗开关（系统级） |
<!-- /GEN -->
