# 昼夜动态主题

内置主题「昼夜动态」：窗口背景会跟着本地时间变化，像一扇随天气走动的窗。

## 怎么打开

设置 → 外观 → 应用主题 → **昼夜动态**。

主题默认开启；想换回普通深色 / 浅色，在同一处选择「深色」或「浅色」即可。

## 背景里有什么

- **清晨 / 黄昏**：暖色天空、地平线暖光和光柱，云层最明显
- **白天**：蓝天与云，太阳按时间从东边升到西边；正午最亮
- **夜晚**：深蓝星空、月亮、星点与萤火；深夜还会有很淡的极光
- **太阳 / 月亮**：06:00 日出、19:00 日落，位置随时间连续移动

背景只作氛围，不抢内容：标题栏、侧栏、内容卡都是半透明玻璃，正经文字仍然清晰。黄昏 / 黎明太阳较低时，内容面板会自动变得更实（约 94~96% 不透明），避免暖光从面板后糊住正文；正午和深夜则恢复更通透的观感。

面板的深浅在 **06:00 日出 / 19:00 日落** 时翻板：日落后面板直接进入深色，日出后进入浅色。天空仍保留约 12 分钟的暖光渐变，但面板不会在傍晚经过一层灰褐色。如果刚好在 19:00 左右盯着界面，会看到一次快速换色，这是刻意的，不是闪烁。

## 专注时自动收敛

设置 → 外观 → **昼夜背景** → 「专注模式降低特效」（默认开）。

- 进入**禅模式（Z1 / Z2）**或**番茄钟专注阶段**时，云、星空、极光和粒子降到约 30% 强度
- 天空、太阳 / 月亮保留，不会突然变成纯色
- 关闭这个开关后，专注时也保持完整特效

## 性能与省电

- 主题按分钟更新颜色，没有持续重绘的 canvas
- 系统开启「减少动态效果」时，云 / 星 / 极光 / 萤火 / 流星会停止运动，颜色仍随时间变化
- 如果觉得背景太抢眼，可以切回深色 / 浅色主题；专注时的粒子强度由「专注模式降低特效」控制

## 常见问题

**背景看不到天空？** 确认主题是「昼夜动态」；弹窗、菜单等需要看清文字的表面仍是实底，这是刻意保留的。

**月亮 / 太阳多大？** 天体大小固定，位置随窗口尺寸换算；窗口最大化后会铺满整窗。

**日程小窗有没有背景？** 独立日程小窗使用定格正午的静态兜底，不跑整窗动画。
