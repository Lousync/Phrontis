局域网常驻同步服务：手机（Phrontis Mobile）与电脑配对后，记账流水 / 日程待办 / 笔记双向同步，全程本地、不经过云端。

## 配对

1. 工具箱打开「手机伴侣」，服务启动后出示**配对码**（8 位，10 分钟有效）；
2. 手机端扫配对二维码，或粘贴配对链接；
3. 也可以走**确认配对**：手机发起请求 → 电脑弹出确认框 → 双屏核对 4 位码 → 点「允许」。手机发起请求时，电脑在任意页面都会收到提示（toast 点「去确认」直达手机伴侣面板），不要求面板已打开。服务常驻时陌生人扫到也拿不到令牌，必须本人在电脑上点允许。

配对绑定当前仓库（防多仓串写）：电脑切到别的仓库时手机端会拒绝同步并提示，切回即恢复。已配对设备可随时吊销。

## 配对码过期与重新出示

配对码有效期 10 分钟，一次配对成功即作废。「换一个配对码」按钮在配对码有效与过期两种状态下都显示，点击即生成新码。二维码只对应当前有效配对码：配对码失效时二维码自动隐藏，不显示旧码；生成新码后二维码按当前选中地址更新。

## 手机可访问的地址

面板「手机可访问的地址」列出电脑各网卡上手机可尝试访问的地址。带「推荐」标记的是与手机同网段的地址（手机最近来过请求的网段优先，其次默认路由出口网卡）；docker、WSL 等虚拟网卡的行标注「虚拟网卡 · 手机通常不可达」。二维码与配对链接使用选中行，点击行即切换；手机连的是哪个 Wi-Fi / 热点，就选与它同网段的地址，不确定时使用推荐行。

## 同步什么

| 域 | 方向 | 说明 |
|---|---|---|
| 记账 ledger | 手机 → 电脑 | 手机记一笔，电脑账本出现同一条 |
| 日程 schedule | 双向 | 手机待办与电脑日程按条目合并，子任务一起 |
| 笔记 notes | 双向 | 见下方「笔记 U 盘模式」 |

同步按「新者赢」合并（同一条两边都改过时，时间新的胜出）；删除也同步（删了的条目不会在另一端复活）。手机离线时改动先记本地，联网后自动对账。

## 实时同步

手机在**前台且已配对**时会与电脑保持一条实时通道：电脑上任何改动（编辑文件、AI 工具、另一台手机的同步）都会在 1 秒内推到手机，不需要手动刷新；反过来手机改了，电脑端也即时可见。手机退到后台时通道自动暂停（省电），回前台自动对平并恢复实时。

手机端同步状态显示「轮询 30s（电脑版本较旧）」时，说明对面电脑还没升级到支持实时同步的版本——同步仍然可用，只是不实时，电脑升级后自动恢复。

## 笔记 U 盘模式

手机笔记不再是收件箱里的一条消息，而是仓库里一棵**双向同步的子树**：

```
<仓库>/
  移动端/
    <设备名>/
      购物清单.md
      会议纪要.md
```

- **像插了个 U 盘**：手机新建 / 改 / 删笔记 → 同步后文件跟着变；在电脑上对文件增删改（编辑器、AI 工具、直接改文件都行）→ 手机实时收到更新（见上方「实时同步」）。
- **设备文件夹只有连接后才显现**：设备离线时文件树里隐藏该文件夹（磁盘文件保留不动，重连后树重现、积压变更照常双向对平）；没有设备在线时「移动端」层也隐藏。
- 文件 frontmatter 里的 `id` 是跨端锚点：标题改动 = 文件改名、`id` 不变；`updated` 是合并裁决时钟，桌面侧改动会自动维护。
- 手机端删除笔记 = 编辑时清空标题保存（上行墓碑，电脑端文件同删）。
- 把仓库里已有的文件复制进设备文件夹（带 `id` 的 frontmatter），手机同步后即可看到——相当于「发送到手机」。
- 「移动端」子树不参与手机端「电脑笔记只读」的内容 API 与正文缓存，两边是两棵独立的树。
- 两端同时改同一条：新者赢自动收敛，不弹冲突卡。
