# AI 教学 · 对话模式

不想建课、只想问一道题 / 读一份资料时，用**对话模式**。它在「选择工作区」页，不要求大纲、章节和素材登记。

## 进入与新建

- 在 **AI 教学 → 选择工作区** 页，搜索框右侧点「**对话**」。
- 左栏是对话列表，按 **今天 / 昨天 / 更早** 分组；顶部可搜索、可点「**新建对话**」。
- 每个对话一个文件夹：`AI教学/对话/{日期 标题}/`。双击列表里的标题可改名，文件夹会同步改名；删除对话时按设置询问是保留、删除还是移入回收站。
- 对话列表只显示对话模式会话；课程工作区里的对话不会混进来。

## 输入卡：方式与资料

输入框上方有两块：

- **方式**（五档）：`自动 / 对话 / 讲解 / 解题 / 先问我`。默认「自动」，每次发送后自动回到「自动」，不会粘住。
  - **自动**：有图片或题干像题目 → 解题；右侧有当前资料且问题指向「这页 / 这段 / 原文」→ 讲解；需求很含糊 → 先问我；其余 → 对话。
  - **对话**：普通问答。
  - **讲解**：按单份资料伴读，先给三句地图，再问你想听哪一层（直觉 / 推导 / 例题 / 考点），引用带页码或小节。
  - **解题**：先问卡点 → 一级提示（方向）→ 二级提示（关键步骤）→ 完整解 + 考点 + 易错点；变式题写在题单围栏里。
  - **先问我**：先出一张澄清卡（2–6 个选项，可自由输入），答完继续原请求。
- **资料 chip**：右侧查看器打开 PDF / EPUB 时，会把当前页或当前章节作为这一轮的「当前资料」。点文件名聚焦右栏，点 `×` 不放资料。文本超过 3000 字只带前 3000 字。

## 回答下方的动作

- **解题回答**（只挂在最新一条解题回复下）：「再来两道变式」会以解题方式再发一轮；「加入题单」把回答里的题目追加到 `产物/题单.md`。聊天回答不是知识页，暂不提供「加入错题」。
- 普通回答：复制 / 整理成文档 / 收藏，与课程会话一致。

## 右侧查看器

网页、笔记、电子书、旁问、文件都在右侧页签里。**每个对话各自记住自己的页签与宽度**；切换到别的对话不会串，也不会把课程工作区的页签带过来。

网页页签按「一个页签就是当前这一页」使用：

- **点站内 / 站外链接、按住 Ctrl 或中键点链接**：都在当前页签里跳转，`←` 能回到上一页；不会把链接丢到系统浏览器。
- **登录 / 授权弹窗**：站点弹出的小窗口在应用内打开（同一套登录态），登录完成后主页面直接生效，**Cookie 保存在本地，重启应用后仍然登录**。
- **要拿到系统浏览器**：点地址栏右侧的 ↗（唯一入口）。
- 网页里的 `mailto:` / `tel:` 仍交给系统的邮件 / 拨号程序；下载一律被拦截。

## 和课程模式的区别

| | 对话模式 | 课程模式 |
|---|---|---|
| 入口 | 选择工作区页「对话」 | 选择 / 新建工作区 |
| 结构 | 无大纲、无章节、无开段预检 | 章 → 知识点 → 段 |
| 文件夹 | `AI教学/对话/{日期 标题}/` | `AI教学/{工作区}/…` |
| 素材 | 不登记 `SOURCES` | 登记 `sources.json` 并按章分配 |
| 进度 / 结课 | 不参与课程统计 | 有进度、交接、章末复习、结课 |

需要长期跟进一门课、留下学习进度时，回到选择工作区页进入课程模式即可；两种模式共用同一套模型、上下文用量与右侧查看器。
