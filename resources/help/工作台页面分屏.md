# 工作台页面分屏

分屏把**页面标签**拆成并排两栏：主栏与副栏各显示一个知识库页面，两个页面同时可见。分屏只搬「页面」，**模块标签不分栏**。入口 = 知识库页面标签上点右键。

## 怎么分屏

在知识库的页面标签上点右键，菜单里有**向右拆分**与**向下拆分**：向右 = 左右两栏，向下 = 上下两栏。被拆的那个页面移到副栏，主栏继续留在原来的页面。**已经在分屏状态时这两项是灰的**，不能再拆第三栏——要换页面先合并回主栏。

## 怎么退出分屏

三种方式：把副栏页面拖回主栏页面条、点页面条右端的**合并回主栏**、或关掉副栏里的页面。**副栏最后一个页面被拖回或关闭时自动合并**回单栏，不留空副栏。单栏时页签右键菜单里没有这两个拆分项。

## 副栏怎么换页面

- 副栏页面条上的标签**直接点击**即切换副栏显示的页面；
- 把主栏的页面标签**拖到副栏页面条**上，该页移到副栏；反向拖回主栏页面条即移回主栏；
- 页面条**右端的「合并回主栏」**按钮把副栏页面全部并回主栏，回到单栏。

拖动分隔条可调整两栏比例，夹在 20% 至 80% 之间。**分屏状态会持久化**：拆了哪几页、方向、比例、各栏当前页都记着，重启软件自动恢复上次的分屏。

## 副栏与主栏的差别

副栏用的是同一个知识库编辑器，正文照常编辑与自动保存。差别在四处：

- 编辑区右上角的**悬浮工具栏只挂主栏**（格式切换、插图、脚注那些按钮）；副栏里要动格式走**编辑器右键菜单**，插图 / 脚注走键盘 `Ctrl` `Shift` `I`、`Ctrl` `Alt` `F`；
- **页面历史（顶栏 `←` `→`）只作用于主栏**的当前页面；
- 单栏时页签右键菜单里的**固定标签**、**关闭**、**关闭其他**、**全部关闭**在主栏；副栏页面条的标签**没有右键菜单**；
- **沉浸阅读（`Ctrl` `Shift` `R`）只作用于主栏**的当前页面。

在编辑器里按 `Esc` 返回也是作用于主栏的当前页面，不作用于副栏。分屏与整窗模块互斥：图标条上的整窗模块（AI教学 / 回收站 / 插件 / 动态 / 书市）铺满全窗时两栏都不显示。

## 不支持什么

- **模块不分栏**：分屏只装页面，左栏与整窗模块都不参与，也没有三栏或四栏布局；
- 分屏只在知识库页面之间，博客、日程、思维导图等其它标签不参与拆分；
- 一个页面**只在一栏**，拖到副栏后主栏页面条上不再显示它；
- 两栏各是一套独立编辑器，同时打开两个长文档时内存占用随之增加。
