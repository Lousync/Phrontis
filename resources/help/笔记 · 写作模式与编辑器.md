# 笔记 · 写作模式与编辑器

写作模式决定**知识库笔记**的编辑区怎么显示 Markdown，分两档：**源码**（默认，显示 Markdown 原文）与**即时渲染**（按排版显示，光标所在段落回到原文）。设置入口 = **设置 → 编辑器与阅读 → 写作模式**，切换后立即生效、不需要重启。本篇同时覆盖编辑区**右键菜单**各项与编辑器内**快捷键**。

## 写作模式在哪设置

设置 → 编辑器与阅读 → 写作模式，两个选项：**源码**（默认）与**即时渲染**。设置是全局的，切换后当前打开的笔记立刻换档，光标落到该文件在这一档上次停留的位置。

只想**临时**看一眼某篇的原文、不想动全局档位：笔记顶栏 `⋮` 里有一项 **查看源码 / 看渲染**。点「查看源码」立刻看到这一篇的 Markdown 原文（可编辑、照常自动保存）；阅读态下点它会**顺带退出阅读态**，否则点了看不见变化。想回到排版显示，再点一次 `⋮` 里的「看渲染」（回到即时渲染档），或用顶栏的阅读切换（`Ctrl` `E` / `Ctrl` `/`）回阅读态。**这项只对当前这一页有效**：换到别的笔记就恢复跟随设置，设置页里的全局档位始终没变。

**即时渲染档的字号跟随界面正文字号**（与阅读态预览完全一致，整体缩放用 `Ctrl` `+` / `Ctrl` `-`）；设置里的「编辑器字号」只作用于**源码档**。

写作模式只作用于**知识库笔记**（`.md` 文件）。非 Markdown 文档（代码、纯文本等）强制按源码档显示 —— 它们在知识库里**同样可以直接编辑**，保存的是原始字节、不会被写入 frontmatter；博客编辑器、存档文本、思维导图编辑器不参与写作模式，始终是源码档。

## 源码档

源码档编辑 Markdown 原文：格式标记（`**`、`#`、链接、`[[双链]]` 等）按设置「**Markdown 标记淡化**」淡化显示，光标所在行保留原始标记。行号由设置「显示行号」控制。AI 内联续写（笔记顶栏右段的 **✨** 按钮）只在源码档出现。

## 即时渲染档

光标不在的内容按排版显示：标题 1–6、加粗、斜体、删除线、行内代码、链接、引用条、无序与有序列表、分隔线。此外：

- **任务列表**的复选框可直接点击，勾选状态写回正文；
- 仓库内的**图片**内联显示（粘贴或拖入图片仍然可用）；引用**仓库里任意位置**的图片都行（`![](图片/照片.png)` 这样写也能显示，不必先把图复制进 `.attachments/`）。路径写错时会显示带路径的破图占位，不会一直停在「图片加载中…」；插入的图片文件本身随仓库保存在仓库根的隐藏目录 `.attachments/`，换电脑 / 换系统打开同一个仓库都不会丢图；
- 行内公式 `$…$` 与块级公式 `$$…$$` 用 KaTeX 渲染；
- **GFM 表格**按表格渲染，并且**可以直接在表格里打字**（见下节）；
- **代码块**渲染成带边框的卡片，含语法高亮与右上角语言标签（如 `js`）；
- **脚注** `词^[注释]` 渲染成虚线下划线的词 + 上标「注」，点一下展开注释气泡；
- **列表**与阅读态一致：有序列表按顺序重编号（源里写 `1. 1. 1.` 也显示 1 / 2 / 3），嵌套层依次换成 `a.` `i.`，并按层缩进；
- **查找**：`Ctrl F` 打开查找面板（`Ctrl G` 或 `F3` 下一个，`Esc` 关闭），选中文字会自动高亮同名处。

## 在渲染后的表格里直接编辑

表格是**唯一不回原文**的块：它始终显示为渲染后的表格，点某个单元格就能直接打字，改动即时写回 Markdown 原文（不需要碰 `|` 管道符）。

| 操作 | 效果 |
|------|------|
| 点单元格 | 光标进这一格，直接打字 |
| `Tab` / `Shift` `Tab` | 跳到下一格 / 上一格（在最后一格按 `Tab` 会新增一行） |
| `Enter` | 跳到下一行同一列（在最后一行按 `Enter` 会新增一行） |
| `Esc` | 退出单元格，焦点还给编辑器 |
| `Ctrl` `Z` | 撤销（和编辑器里同一套撤销栈） |

表格里的换行会被压成空格、`|` 会自动转义成 `\|`，所以格内容不会把表格结构弄坏。**对齐方式**（`| :--- |` 这类）与分隔行本身不渲染，要改就切到源码档改。

## 光标所在段落回到原文

光标所在的**块**显示为 Markdown 原文，其余部分渲染成排版。块 = 一行段落、一个标题、一条列表项或一个代码块（**表格例外**，见上节）。光标移到别处，刚才那一块立即恢复渲染。要改某处的标记，把光标移进去即可。

## 切档后光标回到上次位置

两档各自记住每个文件的光标位置（按「文件 × 档位」记账），切回来就落在上次的位置。

**撤销历史不跨档**：切档后 `Ctrl Z` 撤不回切档前的改动，切档前的撤销栈不会带到新档。切档前的内容不会丢（自动保存照常生效），只是撤不回来。

## 编辑区右键菜单

在知识库笔记的编辑区点右键唤出。两档是**同一份菜单**，各项如下：

- **新增链接**：插入 `[[`（有选中文本时用它作链接标题）并弹出笔记候选；
- **新增外部链接**：插入 `[链接文字](https://)`；
- **文本格式**：加粗 / 斜体 / 删除线 / 行内代码 / 高亮（`==高亮==`）；
- **段落设置**：正文 / 标题 1–6 / 引用 / 无序列表 / 有序列表 / 任务列表；
- **插入**：脚注 / 表格 / 标注 / 分隔线 / 代码块 / 数学块 / 题目围栏；
- **剪切 / 复制 / 粘贴 / 以纯文本形式粘贴 / 全选**。

有选中文本时，格式与链接用选中文本；没有选中时插入占位文字并选中它，直接打字即可覆盖。**段落设置**里「引用 / 无序列表 / 有序列表 / 任务列表」再点一次即取消该格式，标题类不自动取消（点「正文」还原）。**脚注**要求先选中单行文字，未选中时该项不可用。插入块级内容（表格 / 代码块 / 数学块 / 题目围栏等）会自动空一行，不会与上一段粘连；**插入表格后光标直接落在首个单元格**，插完就能打字。

子菜单贴着窗口边缘时会自动翻到另一侧或上移，不会被屏幕边缘截断。

## 编辑器内快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl` `B` | 加粗 |
| `Ctrl` `I` | 斜体 |
| `Ctrl` `K` | 新增外部链接 |
| `Ctrl` `Alt` `1` / `2` / `3` | 标题 1 / 标题 2 / 标题 3 |
| `Ctrl` `Alt` `0` | 正文 |

两个档位用的是同一份实现：点菜单里的「加粗」与按 `Ctrl B` 行为完全一致。**编辑器内的 `Ctrl B` 是加粗**，不是折叠侧栏（焦点在编辑器里时，折叠侧栏的 `Ctrl B` 不生效）。

## 不支持什么

- **即时渲染档没有 AI 内联续写**：该档不显示 ✨ 按钮，AI 续写只在源码档可用；
- 即时渲染档不响应「显示行号」设置；**禅模式**与**打字机**只作用于源码档；
- 即时渲染档**代码块仍然要进源码改**：光标进入时整块回到源码（围栏可见），改完把光标移开即恢复卡片。表格不受此限（见「在渲染后的表格里直接编辑」）；
- **mermaid 代码块**在编辑区按普通代码块显示（阅读态会画成图）；
- 高亮 `==文字==` 与标注 `> [!note]` 可以插入，但阅读态暂无专用样式，按普通文字与引用显示；
- 没有 Obsidian「数据库 / Bases」的对应功能，右键菜单里也没有这一项。
