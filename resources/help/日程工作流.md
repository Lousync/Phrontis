工作流是日程模块里「把一个目标拆成按顺序推进的阶段」的地方。工作流和任务可以一对一绑定：任务删除时工作流一起删除；删除工作流不会删除任务。

## 入口

- 左栏「工作流」：中栏显示全部工作流，按进行中 / 未开始 / 已完成分组。
- 左栏「日历」：周 / 季视图顶部有工作流泳道，阶段条可直接点开画布。
- 任务右栏：打开一个任务，在「工作流」区点「建立工作流」。
- 右栏「工作流」Tab：查看和编辑当前选中的工作流。

## 新建工作流

1. **从任务建立**：任务右栏点「建立工作流」，自动生成「准备 / 执行 / 收尾」三个阶段，日期连续且不重叠。
2. **全局新建**：工作流列表右上角「新建工作流」，填写标题、标签、开始、结束。
   - 「创建空白」得到 0 阶段工作流，进入画布后自己添加阶段。
   - 「AI 拆解」创建工作流后打开 AI 助手并预填提示词，不会自动发送。

一个任务最多绑定一个工作流。再次点「建立工作流」不会重复创建。

## 画布

- 阶段按数组顺序从左到右排列，不保存任意 x / y 坐标。
- 拖动阶段卡片只调整顺序；松手后日期会按新顺序重新连续排布。
- 每张阶段卡片下方挂检查点，检查点不参与阶段序号和进度。
- 支持平移、Ctrl+滚轮缩放、缩放按钮和适应画布。
- 点击阶段或检查点打开右栏工作流 Tab。
- 画布顶部「添加阶段」追加一个默认 3 天的阶段。

## 日期规则

- 阶段日期只使用 `YYYY-MM-DD`。
- 相邻阶段不重叠；重排或改日期后，后续阶段自动顺延。
- 改阶段开始日落入上一阶段内部时，会被夹到上一阶段结束日的下一天。
- 检查点始终被夹在父阶段日期范围内。
- 工作流范围会自动覆盖所有阶段，不会把阶段截断。

## 右栏工作流面板

- 改标题、标签、工作流范围。
- 阶段列表：状态点、标题、日期、里程碑、检查点。
- 阶段状态按「未开始 → 进行中 → 已完成」循环切换。
- 按钮：添加阶段 / 在画布中打开 / 在日历中查看 / 删除工作流。
- 删除工作流只删除工作流，任务保留。

## 日历

- **周**：上方工作流泳道，下方 7 天任务列；阶段条可左右拖动改日期。
- **季**：14 周工作流泳道，阶段条按周跨列显示。
- **月**：任务 chip 为主，每天最多两条工作流色线；色线悬停显示工作流 / 阶段 / 日期。
- **日**：当天任务 + 当天阶段。

## AI 工作流能力

日程助手拥有完整工作流读写权限：

- 查询工作流、读取完整阶段与检查点。
- 创建独立工作流或绑定任务的工作流。
- 修改标题、标签、范围。
- 增加 / 修改 / 删除阶段，重排阶段。
- 增加 / 修改 / 删除检查点。
- 删除工作流。

日期顺序由工具统一归一化，AI 不需要自己计算阶段是否会重叠。删除任务会级联删除它的工作流。

## 当前限制

v1 只支持线性阶段，不支持并行、分支或 DAG。工作流不保存自由坐标；自由白板规划属于后续升级项。
