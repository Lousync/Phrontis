每日习惯打卡,用连续天数与完成率激励坚持,支持补卡、归档与统计回顾。

## 创建习惯

点击左栏「+」新建习惯:

- **名称**:如「阅读 30 分钟」,输入框内按 `Enter` 直接保存
- **颜色**:10 色色板,用于打卡圈、日历圆点与统计卡片
- **打卡规则**(三选一):
  - **每天**
  - **每周指定**:勾选星期几(如周一、三、五)
  - **每周 N 次**:灵活目标(如每周 3 次即可)

## 三个视图

### 今天

- 列出当天计划内的习惯,点击卡片即打卡 / 取消,打卡瞬间有彩带反馈
- 顶部显示「已完成数 / 计划数」进度条,全部完成触发全屏庆祝

### 日历

- 月历上每天最多显示 4 个彩色圆点(对应当天已完成习惯的颜色),超出显示「+N」
- **点击任意日期**展开当日明细,可直接勾选 / 取消——这就是**补卡与撤销**入口;已归档习惯当天打过卡的以划线形式只读展示

### 统计

每个习惯一张卡片:**当前连续**、**最长连续**、**累计次数**、**近 30 天完成率**(≥80% 绿色,<40% 警告色);灵活目标习惯显示「本周 n/N」。

## 连续与里程碑

- 连续天数只按**计划日**计算:今天还没打卡不断档,非计划日自动跳过
- 命中里程碑(3 / 7 / 14 / 21 / 30 / 50 / 100 / 150 / 200 / 250 / 300 / 365 天)时会弹出祝贺提醒

## 与手机同步

手机伴侣配对后，习惯定义与每日打卡记录双向同步：

- 电脑新建 / 改名 / 改周目标 / 归档 / 删除习惯 → 手机同步；手机新建 / 编辑 / 删除习惯 → 电脑同步。
- 电脑打卡 / 补卡 / 取消 → 手机当前周圆点更新；手机打卡 → 电脑记录出现。
- 手机只显示当前周，电脑保留完整历史；手机的连续天数按同步到的历史记录计算。
- 手机打卡提醒仍在手机本地设置；电脑端提醒不受影响。
- 两端同名但不同来源的旧习惯会作为两条独立习惯出现，删除重复项即可。

## 提醒与归档

- **打卡提醒**:到 **设置 → 提醒** 中开启,默认每天 20:00;到点若当天仍有未打卡习惯会弹窗提醒(每天至多一次,错过时间打开应用会补提醒)
- 暂时不做的习惯可**归档**(划线灰显,可随时恢复),归档不丢失历史记录
- 删除习惯会**连带删除其全部打卡记录**,需二次确认
