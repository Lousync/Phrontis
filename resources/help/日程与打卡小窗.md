主窗口之外的独立伴随小窗,把「今天要做什么」和「今天打卡了没」常驻在桌面一角,不用切模块就能看和改。

## 打开与关闭

| 操作 | 方式 |
|------|------|
| 开关小窗 | 标题栏右侧日历图标按钮,或全局快捷键 `Ctrl` `Alt` `S` |
| 关闭小窗 | 小窗右上角 `×`,或小窗内按 `Escape` |
| 重新打开 | 同上开关方式(关闭只是隐藏,数据不丢) |

启动应用时不会自动弹出小窗,需要时再打开。

## 窗口摆放

- **默认吸附**:小窗默认贴在主窗口右缘外侧,主窗口移动 / 缩放 / 最大化时自动跟随
- **拖离**:按住小窗顶部标题栏拖动,即可脱离吸附自由摆放;位置会被记住
- **磁吸回位**:自由摆放状态下把小窗拖近主窗口右缘,左缘会出现磁吸气泡提示,松手即自动吸附回去
- **标题栏图钉按钮**:已吸附时显示「脱开」图标,未吸附时显示「吸附」图标,点击立即回位
- **跟随最小化**:主窗口最小化 / 还原时,小窗自动一起隐藏 / 恢复
- **尺寸**:小窗宽高可自由拖动调整并记忆;吸附状态下只跟随位置,不再被主窗口高度绑定

右侧屏幕空间不足时(比如主窗口已最大化),小窗会自动改贴主窗口右缘内侧,不会跑到屏幕外。

## 面板内容

### 逾期

置顶红色分组,列出**全部**日期早于今天且未完成的顶层任务,按日期从早到晚排列。悬停任务行可:

- 📅 改到今天(一键把逾期任务挪到今天)
- ✏️ 编辑标题 / 日期 / 时间
- 🗑️ 删除

### 今天

列出今天的顶层任务,点击方框勾选完成。点任务左侧的箭头可展开一级子任务,子任务同样能勾选和删除。

右上「任务模块」跳转到主窗口的日程模块,用日历、四象限等完整功能。

### 快速添加

输入一句话即可建任务,日期和时间会自动识别:

| 输入示例 | 识别结果 |
|----------|----------|
| `明天下午3点开会` | 明天 15:00 |
| `周五 14:00 复习计网` | 下一个周五 14:00 |
| `下周三交作业` | 下周的周三 |
| `8月5号交报告` | 今年 8 月 5 日(已过则算明年) |
| `25号取快递` | 本月 25 日(已过则算下月) |
| `复习第3章` | 今天(正文里的数字不会被误认成日期) |

识别结果会显示在输入框下方,**日期和时间可以直接点开修改**,改完回车即可;点「重解析」恢复自动识别的结果。没识别到日期默认今天,没识别到时间就是全天任务。

### 今日打卡

列出今天计划内的习惯,点击右侧圆圈即可打卡 / 取消打卡,并显示连续天数。底部输入框可快速新增习惯(规则默认每天,更详细的规则去工具箱的「习惯打卡」配置)。

右上「完整配置」跳转到主窗口工具箱的习惯打卡页。

## 与主窗口日程的差异

小窗的快速添加保留原有的日期 / 时间解析。主窗口日程的「今天」页还支持：

- `#标签名`：按标签名匹配，找不到时自动建标签。
- `1h` / `30m`：写入预计时长。
- `截止 18:00` 或 `截止 2026-10-30 18:00`：建成截止类任务。
- 收集箱任务（没有日期）不会出现在每一天的今日列表里。

## 数据同步

小窗与主窗口共用同一份数据,任一侧的增删改都会立刻反映到另一侧,不需要手动刷新。跨零点时小窗会自动翻到新的一天。
