日程助手是日程模块里的 AI 排程助手,入口在日程模块右栏的「🗓 日程助手」页签(切到日程模块时出现)。它只处理日程与待办(排期、优先级、提醒),不涉及知识库、记账、学习。本页覆盖:一句话加任务、排期预览、今日简报、会话、固定日程(重复任务)、任务类型与时间识别。

## 日程助手的入口

日程助手在日程模块**右栏**的「🗓 日程助手」页签里;该页签只在日程模块激活时出现。日程助手与通用 AI 助手(`Ctrl` `J`)的会话**互相独立**:两者的会话列表互不可见,日程助手只调用日程相关工具、不读知识库笔记文件。

## 一句话加任务

对日程助手说一句话即可建任务,如「明天 15:00 和 A 组队做实验 2 小时」。

- 句子里**带时间**(几点、几点到几点、几小时)→ 任务直接排进「周日程」的时间格,成为排期时段。
- **不带时间** → 任务进入「待安排」栏,等待排期。
- 「周五 23:59 前交报告」这类 → 建成**截止类**任务,带截止时刻,只在日程表画一条红线、不占时间格。

## 排期预览(指令 `/排这周`)

发送 `/排这周`,日程助手把「待安排」里的任务排成一份**排期预览**(一周速览 + 逐条 时间 / 任务名),并说明是否与已有安排冲突。点预览卡上的「确认排入」助手才逐条落盘;点「调整」可改;点「打开周日程」跳到日程表核对。**截止类任务不参与排期预览**(不占时间格)。未经确认不会批量改期。

## 今日简报(指令 `/简报` `/今天` `/拆解`)

- `/简报`:按今日待办、逾期、待安排给一份今天的安排。
- `/今天`:按截止紧迫度与四象限给建议顺序。
- `/拆解`:把一个大任务拆成子步骤。

## 一天一个会话

日程助手**一天一个会话**:当天第一次打开会新建一个以日期命名的会话(如「10月11日 周日」);再次打开仍回到这个会话,到第二天自动换新的。会话列表按日期显示。

## 固定日程(重复任务)

固定日程用于「每周 / 每月 / 每隔几天自动出现」的事,如「每周六下午洗衣服」。

- **手动建**:日程模块左栏「🔁 固定日程 → ＋ 新增」,填事项 + 重复方式(`每周` / `每月` / `每N天`)+ 时段。
- **对助手说**:「每周六下午我要洗衣服洗袜子」,助手建成规则(建之前先给你确认)。
- 到那天自动生成一条待办,占在日程表时间格上(带 🔁 标记),可勾选完成。**某次没做不顺延**,下次照常出现。
- 规则可编辑 / 暂停 / 删除;**删除规则不会删掉已生成的待办**。

## 任务类型:截止类 / 计划类 / 零碎

日程任务分三类:

- **截止类**:有截止时刻的任务(交报告、考试、报名截止),带截止时间,在日程表画一条红线、不占时间格。
- **计划类 / 目标类**:要推进但无固定截止的目标(复习完第三章),可写「完成标准」。
- **零碎**:当天随手完成的小事。

对日程助手说「周五前交报告」会建成截止类;说「复习完第三章」会建成计划类。

## 时间识别

日程助手知道当前的日期、星期与时刻,能把「今天 / 明天 / 下周X / 这周末 / X 天后 / 过会儿 / 今晚」换算成具体日期(必要时含时刻)再安排,不需要手动换算。通用 AI 助手与 AI 教学同样可以查询当前日期与时间。
