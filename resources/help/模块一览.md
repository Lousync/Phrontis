# 模块一览

Phrontis 的功能分**工作台内**与**整窗**两类。工作台是启动后固定落到的页签（点顶部「工作台」按钮随时回来），三栏外壳（图标条 · 左栏 · 中间内容区 · 右栏）始终在；点左栏书签就在工作台内换内容，外壳不动。整窗模块（图标条上的那几项）点开则铺满全窗、三栏退场，返回靠模块自己的返回入口。

中间区最上面那一行是**页面条**（模块页签 + 笔记页签 + 尾部动作同排）。**页签开多了不会挤丢**：这一行按需横向滚动——鼠标滚轮停在页面条上就直接横滚（Shift+滚轮与触控板横向手势同效），溢出的一侧会渐渐淡出提示「这边还有」，而**当前页签始终自动滚回视野**，切模块或开新页面都不用自己去找。

共 21 个模块（开发者工具仅 dev 版可见，日常 20 个）。模块清单的唯一来源是 `appModules.ts`，本文与其同步维护。

## 工作台内有哪些（左栏书签）

左栏书签固定 **8** 项，点它们在**同一套三栏外壳内**切换内容——左栏、中间、右栏是共用的一副框架，不是分别打开几个窗口：

- **看板**：打开软件第一眼的总览落点，整窗显示。
- **笔记**：知识库主体——页面读写、文件树、全文检索、`[[双链]]` 与右栏「关联网络（引用 / 被引用）」、知识图谱入口、**页面分屏**（页面标签右键「向右拆分 / 向下拆分」，两个页面并排）。关掉笔记区**最后一个页面不会退出笔记模块**：左栏仍停在文件树、中间显示空态，可继续开其它文件。该空态里有一枚「**回工作台**」按钮：笔记模块在没有页面时页面条上**不出现条目**、左上角「工作台」按钮在工作台内也不响应，所以这个按钮是回到工作台总空态的入口。
- **日程**：待办、四象限与打卡小窗。
- **书架**：本地电子书阅读器（PDF / EPUB 等六种格式）。
- **博客总结**：博客写作与每日日记。
- **记账**：收支流水、手机 AI 生成的 JSON 导入、账户余额与统计复盘。
- **终端**：内置终端会话与 AI 命令执行记录。
- **AI助手**：先在左栏圈定范围（目录 / 文件），再让 AI 读取并**修改**仓库里的 md 文件——改动先暂存成变更方案、出并排 diff 再逐条确认，可整任务回滚；范围**随任务各自保存**，任务运行中锁定，任务条目双击可改名。

**工具箱**同样在工作台内：入口是命令面板 Ctrl+Shift+P 搜「工具箱」，或在工作台把它钉成磁贴。它打开时铺满中间区，与上面五项一样属于工作台的内容切换。

看板（桌面）上的「**添加控件**」面板可把模块钉成磁贴：分「内容控件」（磁贴里直接显示内容，如待办、番茄钟）与「模块入口」（点一下进模块）两组，终端与记账也已支持钉成磁贴。

书签数据源里还登记着**错题本**，但它的显示受总开关 `QUIZ_ENTRY_ENABLED` 控制，当前版本**不渲染**（后续版本随交互重做放出）。

工作台中间在**没有打开任何页签时显示空态**（启动首屏即是，关掉全部页签也回到这里）：空态里除了一枚页面图标，还固定摆着三条指令——**打开命令面板（Ctrl+Shift+P）**、**快速打开文件（Ctrl+O）**、**AI 助手（Ctrl+J）**，点击任意一条与按对应快捷键等效。

## 图标条有哪些模块（整窗）

最左窄列图标条固定 **6** 项，点开是**整窗**模块——左右栏与页面条退场，整个窗口归它。可拖拽排序、右键可显示或隐藏（顺序与显隐存于设置的 `railOrder` / `railHidden`）：

- **AI教学**：出题、教学与学习路径；可把工作区升级为「课程模式」（课程大纲 / 上课 / 课程助手），并支持输入斜杠指令 `/mindmap` 生成思维导图、`/生图` 生成图片（图落本会话文件夹 `outputs/`，在右栏工件栏看图）。
- **回收站**：已删除内容的找回（删除内容先进这里，非彻底删除）。
- **插件**：插件市场与已装插件管理（含插件权限与签名）。
- **动态**：动态与心情记录。
- **书市**：在线书源检索与电子书下载。
- **用量**：本机全部 AI 调用的 token、估算费用与调用次数（看板 / 热力图 / 按模型拆分），以及各供应商的账户额度。

顶部「工作台」按钮与底部「设置」按钮由外壳固定，不参与排序与显隐。

## 其余入口

- **知识图谱**：知识库链接的可视化。入口 = 笔记模块内跳转；它是一个独立页签，关闭后再从笔记模块内重新进入。
- **AI对话**：整窗 AI 会话页签。入口 = AI 侧栏头部 ⤢ 按钮（侧栏用 Ctrl+J 唤出）。多个会话可同时运行：切换会话不中断正在进行的回复；会话列表条目转圈表示该会话正在回复，亮蓝点表示后台已完成未读，红色感叹号表示后台失败；同时最多 3 个对话在运行，「停止」按钮作用于当前查看的会话。**回复生成中的样子**：正文上方只有一条会来回滑动的进度线 + 阶段文字（不画外框、不放转圈），回复超过 3 秒才会在右侧安静地出现一个耗时（每秒跳一次，不是跳数字的秒表）；**工具调用在生成中不显示**，完成后再收成一行「用了 N 个工具」摘要；**停止入口只有输入区那一个** —— 生成中发送键会变成「停止」（AI 教学中栏是圆内方块，侧栏与全局面板同款）。长期跟进的会话可**钉住**——会话行尾点 ★，或右键菜单选「钉住到收藏」；钉住的会话集中到列表顶部「★ 收藏」分区（整页左栏与悬浮/右栏抽屉都支持），再点一次即取消。
- **帮助**：本手册中心。入口 = 工作台磁贴，或命令面板搜「帮助」。
- **更新说明**：版本更新内容。major.minor 版本变化后首次打开自动弹出，之后可从磁贴或设置进入。
- **设置**：全局设置（含 AI 工具权限）。入口 = 外壳底部「设置」按钮。

## 命令面板能直达什么

Ctrl+Shift+P 打开命令面板，可直达 14 项：笔记、博客、日程、动态、AI教学、工具箱、终端、插件、书市、回收站、用量、帮助、设置、记账。

书架 / AI对话 / 知识图谱不在面板清单中——它们是**入口产生型页签**，从对应入口（左栏书签、AI 侧栏 ⤢、笔记模块内跳转）打开，关闭后再从原入口进入。看板同样不在面板中，它只从左栏书签进入。AI助手也只从左栏书签（或桌面磁贴）进入，不在面板中。更新说明也不在面板中，走设置或磁贴。
