# 笔记 · 主题与总览

笔记区左栏有三个视图：**最近**、**主题**、**结构**。三者共用同一份仓库笔记，只是组织方式不同——不复制、不搬文件。

三个视图**都有搜索框**，但搜索的含义跟着视图走：

- **最近**：按标题 / 摘要 / 标签 / 目录名过滤笔记；
- **主题**：按主题名 / 描述 / 成员笔记标题过滤主题卡；
- **结构**：**查找并定位**——输入后在树区列出匹配的目录与笔记（标题 + 路径），点一条即展开祖先目录并滚到它；按 `Esc` 清空回到目录树。

顶部按钮也按视图给：**＋ 新建**三个视图都有；「排序」在最近与结构；「展开 / 收起」只在结构；「聚焦」（准星）在最近与结构。只在结构有用的动作不会出现在其它视图里，也不会点了之后替你切过去。

## 最近（笔记流）

按修改时间平铺所有笔记，分「今天 / 昨天 / 本周 / 更早」四组，可以折叠分组。

- 每行两行式：标题 + 「所在目录 · 正文摘要」，右侧显示最近修改时间；
- **新建笔记**：点顶部「＋ → 新建笔记」，列表最上方出现一行输入框（右侧小字是落点），回车即创建并打开，**不会切到结构视图**；
- 头部「排序」可切 **最近修改 / 标题**，选择会记住；
- 头部「聚焦」（准星）只保留当前打开笔记所在的顶层目录，再点一次取消；
- 右键任一笔记打开菜单：打开、**加入主题…**、新建主题并加入…、在结构树中定位、删除。

## 主题（虚拟集合）

**主题不是目录。** 它只是一组「哪些笔记属于它」的名单，可以横跨多个目录，一篇笔记也可以同时属于多个主题。

- **新建主题**：点左栏顶部「＋ → 新建主题」，或主题视图里的「＋ 新建主题」，输入名称回车；
- **加入主题**：在主题视图里，把一张主题卡上的笔记**拖到另一张卡**上；或者右键任意笔记选「加入主题…」，勾选已有主题（再点一次移出）；
- **主题卡**显示成员数、跨几个目录、最后更新时间和前几篇笔记；点标题打开主题详情；
- **未归类**：不属于任何主题的笔记。点它进入「未归类」页；所有笔记默认都在这里，不会因为放在某个目录就算已归类；
- **改名 / 删除**在主题详情页：删除只解散集合，**笔记全部保留**，不会删文件。
- **AI 也能整理**：让 AI「把这几篇加入面试高频」即可，它只改成员关系、不移动文件；主题不存在会按名字新建（需要知识库模块对 AI 开放写入）。

拖动只改「成员关系」，**不会移动文件、不会改正文**。想移动文件，去「结构」视图拖目录。

## 结构（真实目录树）

与工作台文件树同一份实现：展开目录、打开文件、右键新建 / 重命名 / 创建副本 / 将文件移动到… / 导入 / 删除，拖行首图标移动文件。这里的层级就是仓库里的真实文件夹。

结构视图的「＋」里是**新建笔记 / 新建目录**（都在树内联命名）；「展开 / 收起」与「排序」也只在这里出现。搜索框在这里是**查找并定位**，不会过滤树本身（树按需加载，过滤会漏掉未展开的目录）。

## 主题详情页

点主题卡标题会在页面条末尾开一个**主题标签**（同时只开一个，不参与分屏 / 固定）。详情页里：

- 顶部是主题名、描述、`N 篇 · 跨 M 个目录`，可以重命名或删除；
- 成员**按目录分组**，点条目打开笔记，悬停右侧 `×` 把这篇移出主题（可撤销）；
- 删除走行内确认卡，不动任何笔记文件。

## 总览

页面条最左边是**总览**固定标签，不可关闭。内容：

- 继续上次编辑（最近打开的笔记）、本周新增 / 已归类 / 未归类三个统计；
- 最近修改、主题集合、标签云、未归类快捷入口；
- 「回工作台」按钮。

点总览标签只是切换显示，**不会关闭已打开的页面**；关掉最后一个页面标签会回到总览。

## 阅读时左栏自动变成大纲

打开一篇 Markdown 笔记且处于**阅读态**时，左栏自动换成大纲（标题搜索 + 点击跳转）。

- 点左栏「返回列表」回到笔记流；切到编辑态也会回到列表；
- 换到另一篇笔记时重新按阅读态判定，不需要手动切回；
- 非 Markdown 文件（PDF / 图片 / 文本）没有标题结构，左栏保持列表。

沉浸阅读（Esc 退出）仍是大纲，退出后回到你进入前那一栏。

## 数据存在哪

主题名单存在仓库的 `.knowbase/modules/knowledge/topics.json`，只记 `pageId` 成员关系：

- **不写 Markdown frontmatter**，不改正文；
- 笔记改名、移动目录、AI 搬文件都不断链（成员记的是稳定 id）；
- 换电脑拷走整个仓库文件夹即可，主题名单跟着走；
- 仓库里没有 `topics.json` 就是「还没有主题」，所有笔记都在未归类——不会自动按目录生成主题。
