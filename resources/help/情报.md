# 情报

情报是工作台内的信息流模块：从 8 个技术资讯源抓取条目、按质量分排序、应用内阅读正文，收藏或存为笔记。入口 = 左栏书签「情报」，也可钉成磁贴或从命令面板打开。数据存仓库 `.knowbase/modules/intel/`，换电脑拷走仓库即带走。

## 数据源有哪些

共 8 个源，全部免 Key 免登录：GitHub 新晋高星（近 7 天创建、Star 增长最快）、Hacker News（前页）、arXiv（cs 类目最新论文）、OpenAlex（全学科论文）、阮一峰科技爱好者周刊（最新一期内的文章）、HF Daily Papers（社区点赞的每日 AI 论文）、AI 官方博客（DeepMind / OpenAI / Anthropic，标题前缀区分）、量子位（中文 AI 资讯）。单源失败不影响其余源；顶栏会显示「N 源失败」，下一轮自动重试。

## 怎么抓取

点模块顶栏「刷新」立即抓取一轮，Toast 报告新增条数。自动抓取在设置 › 模块 › 情报 › 自动抓取间隔里设（关闭 / 每 1 小时 / 每 3 小时 / 每天），应用运行时到点自动拉新。每个源每轮最多入库「每源单轮上限」条（默认 20）。命中营销特征词的条目在入库前拦截，可在设置里关闭。

## 质量分是什么

每条情报有一个 0~100 的质量分，列表按分数降序：源权重（人工精选源更高）+ 热度对数缩放（Star / 点赞 / 被引）+ 技术信号词 + 摘要完整度 + 新鲜度。质量分只做排序参考，不拦截内容。

## 条目会保留多久

超期未收藏的条目自动清理，默认保留 14 天（设置 › 模块 › 情报 › 条目保留天数）。**收藏的条目永不过期**；正文缓存随条目一起清理。已打开的文章页签若条目被清理，会显示「该条情报已过期」并提供返回按钮。

## 怎么读正文

点卡片新开一个文章页签（可关闭、可开多个）。正文由应用内提取管线转成 Markdown 渲染，公式与代码高亮可用。部分站点（动态渲染 / 反爬 / 登录墙）无法提取正文，此时页内给出原因、「重试」按钮与「在浏览器打开」兜底。正文只读，笔记的写入统一走编辑器。

## 怎么收藏与存为笔记

卡片右下角 ♥ 或文章页「收藏」按钮即收藏，收藏夹在左栏「♥ 收藏夹」。「存为笔记」把正文存成仓库草稿 `.knowbase/_draft/intel/<日期>-<标题>.md` 并在编辑器打开——无 frontmatter id 不进知识索引，整理后补 id 移入库内即转正（与网页剪藏同一机制）。

## 情报助手能做什么

右栏出现「📡 情报助手」条件页签（情报模块激活时），是与通用助手隔离的独立会话。它能：推荐几篇值得读的（结果收进左栏「✨ AI 推荐」，再问即刷新，点 ✕ 清空）；按关键词找资料；「只看论文」「只看中文」「只看某源」直接改列表筛选。情报助手只读情报池，不处理日程、知识库等其它事务。

## 通用 AI 助手与情报的关系

通用助手（右栏 AI / AI对话 / AI助手模块）可查询情报池，但**只读**：不能刷新「AI 推荐」、不能改筛选——这些写动作只在 📡 情报助手里可用。在通用助手里问「情报池里最近有什么高星项目」可以得到回答。

## 每日简报在哪

顶栏「简报」按钮当前为占位（置灰），每日简报功能计划在 3.12.x 提供，当前版本没有简报生成能力。

## 设置项在哪

路径：设置 › 模块 › 情报（模块顶栏 ⚙ 直达）。可设：自动抓取间隔、8 个源各自的开关、每源单轮上限、营销拦截开关、条目保留天数、HF API 基址。HF（HuggingFace）直连不稳时，把基址改成镜像（如 hf-mirror.com）即可，改动即时生效。

## 不支持什么

抓取不带任何用户数据、无遥测；不在应用内打开任意网页（原文一律跳系统浏览器）；不支持 RSS 自定义源（仅内置 8 源）；不支持登录后才能访问的站点；无每日简报（3.12.x）。
