# 快速上手

**Phrontis 是一款本地优先的学习生活工具**：知识库、日程、打卡、AI 教学都在这一个软件里。**数据 100% 存在本机**：没有云端、没有账号，正文就是普通的 Markdown 文件，换电脑 = 把仓库文件夹拷走。读完本篇约 5 分钟即可独立上手。

## 启动后看到什么：三栏外壳

启动后固定落在「**工作台**」页签（点顶部的「工作台」按钮随时回来）。外壳分三栏：

- **图标条**（最左一列小图标）：AI 教学 / 回收站 / 插件 / 动态 / 书市。可拖拽排序，右键图标可显示或隐藏。
- **左栏书签**：看板 / 笔记 / 日程 / 书架 / 博客总结 / 错题本。**它们不在图标条上**——这是新用户最常见的困惑点。
- **右侧标签页区**：点开的模块各占一个页签。底部固定「设置」按钮；命令面板 **Ctrl+Shift+P** 可直达任一模块（含工具箱、帮助）。

左栏还有第三种形态：点左栏头部的 🌳「切换为文件树模式」，左栏换成**整个仓库的文件树**，可展开目录、右键新建或管理文件。详见《工作台左栏与文件树模式》。

首次启动会先让你选或新建一个**仓库文件夹**（所有数据都存在里面），随后弹出 6 步新手引导，可以跳过，之后在帮助里随时补课。

## 怎么写下第一篇笔记

1. 点左栏书签「**笔记**」，在文件树里**右键 →「新建文件」**，起个名字。
2. 点开这个文件，直接进入编辑页签，输入内容即可，**自动保存，不需要 Ctrl+S**。
3. **不需要手动写 frontmatter**：首次保存时软件自动补上 id 等身份字段，笔记立即出现在全文检索和知识图谱里。
4. 文件真实存在于仓库文件夹里，用资源管理器打开就能看到对应的 `.md` 文件。

在仓库里用资源管理器新建、改名、删除文件后，软件内的列表与文件树**会在约 1 秒内自动跟上**，不需要手动刷新。

笔记的「读」与「写」在同一个模块里完成：浏览、组织、编辑不分家；**侧栏的树和列表只负责组织与管理，不能在侧栏里写内容**。

## 不想让某些文件进知识库？用 .ignore

在仓库根目录（与 `.knowbase` 同级）新建一个名为 `.ignore` 的文件，用 gitignore 语法每行写一条规则，保存后立即生效：

```
私人草稿/
*.log
临时素材*.md
```

被忽略的文件会从知识库列表、搜索、图谱和 AI 检索中**彻底消失**——文件本身仍在磁盘上，不会被删除或改动。三个要点：只认仓库根这一个 `.ignore`，子目录里的同名文件无效；目录名里的空格要原样对齐（推荐在文件树右键目录 →「复制相对路径」再粘贴）；规则没命中任何文件时知识库会弹提示，看到就回头检查拼写。详见《.ignore 知识库隐藏规则》。

## 怎么问 AI：软件怎么用直接问它

- **Ctrl+J**：工作台内唤出右栏 AI 侧栏，再按一次收起。
- 侧栏头部的 **⤢** 按钮：展开为整窗「AI对话」页签。
- **软件用法问题直接问它**（「怎么备份」「某个功能在哪」），它会先检索官方手册再回答；手册里没有的它会明说，不会编造软件行为。
- AI 还能调用工具读写你的数据，权限按模块控制：**设置 → AI 工具**。某模块设为禁止后，AI 就完全看不到它。

## 数据存在哪？怎么备份？

- 全部数据在**本机的仓库文件夹**里，无云、无账号。**整个文件夹拷走 = 备份**，拷回来 = 恢复。
- 工具箱 →「**导出**」可以打一个 ZIP 包。
- 删除的内容会进**回收站**模块，可随时找回，不是立即彻底删除。

## 常见第一坑速查

- **检索 / 图谱里没有我刚写的笔记** → 确认文件保存在仓库文件夹内；刚改动的文件稍等片刻或切换模块后刷新。
- **不想让某些文件进检索 / 图谱** → 仓库根建 `.ignore` 文件写规则（见下一节）。
- **找不到笔记 / 博客 / 日程入口** → 它们在左栏书签，不在图标条。
- **找不到工具箱入口** → 按命令面板 Ctrl+Shift+P 搜「工具箱」，或在工作台把它钉成磁贴。
- **误删了内容** → 去回收站模块找回。
- **AI 说改好了但界面没变** → AI 写盘后界面会自动刷新；没变说明这次没写成功，重试或展开回复里的调用轨迹查看。
- **Phrontis 不联网也完全可用** → 联网只是 AI 的可选能力，不是软件运行的必要条件。
