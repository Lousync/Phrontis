# AI 教学 · 课程模式

AI 教学的**整个工作区**就是一门课——没有单独的「课程模式」开关。课程结构只有两层：**章 → 知识点**；一段对话可以覆盖同一章的多个知识点。

## 建课：和课程助手说

1. 进入工作区，点左栏顶部的**课程助手**（没有大纲也能用）。也可以先在右栏「素材」登记资料——没有大纲也能登记，大纲生成后再按章分配。
2. 把学习目标、资料路径 / 目录 / 网址交给它。它会用 `course.sources.register` 把资料登记进本课程的 `sources.json`：仓库内的文件只引用，仓库外的文件会复制进 `{工作区}/SOURCES/`。
3. 条件够了，助手会给出**全量大纲**（章 → 知识点）的 `outline` 草稿卡。草稿只挂在给出它的那条回答末尾；不满意继续让它改，满意点「**正式生成**」写入 `课程.md`。
4. 大纲落盘后，让助手把素材**按章分配**（能判断页码 / 标题区间就带区间；判断不了就整章）。分配是计划，不是开讲确认——每段开讲前还会再确认一次。
5. 课程助手只负责建课 / 改大纲 / 分素材 / 答疑，**不逐知识点开讲**。大纲落盘 / 更新后它只引导你去左栏点知识点开段，不会在助手会话里直接开讲。开讲由你在左栏点知识点触发。

## 左栏：课程树

- **课程助手**一行：建课 / 改大纲 / 登记与分配素材。
- **搜索**：按章名 / 知识点名过滤；命中后自动展开对应章 / 段。
- **章 → 段 → 知识点**：章头显示 `已学 x / y`，有进行中段时带 `进行中` 徽章；段头显示 `第N段 · 进行中/已收尾 · N 个知识点`。进行中段默认展开，已收尾段默认折叠；点段头打开该段对话。
- **知识点行**：当前聚焦为 accent 实心点并高亮；本段内未聚焦为 accent 空心点；已学为 success 点；未开课为灰点。
- **章末复习**：排在最后一个知识点后；本章知识点全部学完后解锁。复习行**不计入** `x/y`。
- **收藏**与**资源管理器**照旧。

点知识点的行为：

- 在本段里 → 切换本段聚焦知识点。
- 已学 → 回看最近一次覆盖它的段。
- 未学 / 不在本段 → 打开**开段预检**；如果本章已有一段没收尾，会提示先收尾。

## 开段预检

预检在中栏整页显示，不是弹窗：

1. **本段知识点**：本章未学知识点复选；默认从被点的知识点开始连续选最多 3 个。
2. **本段素材**：列出本章分配，并按文件名 / 标题尝试缩窄到本段选中的知识点，标记「精确 / 缩窄 / 整章」；匹配失败自动回退整章。
3. **上一段交接**：同章上一段收尾时生成的交接，可折叠预览。
4. 点「**开始本段**」后，本段确认的素材区间会作为**段快照**写进进度；之后再改本章分配，不影响已开的段。

## 一段里怎么学

- 顶栏显示本章 / 第 N 段 / 本段知识点数量与当前聚焦；右栏「进度」可随时打开。
- 点左栏本段内的知识点切换聚焦，AI 会围绕本段列出的知识点讲；输入区不再放知识点胶囊。
- 上一段交接条只在发出第一条消息前显示，方便开段前阅读；发出后自动收起，回看请打开上一段的 `交接.md`；本段素材条只列**本段确认**的素材。
- AI 仍可出题（题目落成知识库里的 `quiz` 文档，答错回错题本）、画示意图、生成思维导图；产物进右侧工件分栏。
- 题单支持选择题和简答题：简答题在题单内作答，草稿自动保存；展开参考答案后可自评「答对了 / 答错了」。题单顶部有「错题重做」，只抽当前题单判错的题，带着上次答案重做。
- 讲完点「**收尾本段**」：本段冻结为只读，段内知识点全部记为已学，并异步生成 `交接.md` 给同章下一段。
- 交接只由「收尾本段」生成一份 `交接.md`；对话里不会另写交接文件，重复收尾也会复用已有交接。

## 回答中断了怎么办

- 网络 / 模型服务卡住时，流式输出可能中途停下。中断前已经生成的正文会留在对话里（标注「可能不完整」），不会再整段消失。
- 中断卡下方有「**继续**」：点它从断点接着写，不重发你的上一条消息；已经查过的工具结果也会保留。
- 你点输入区的停止键属于主动中断，同样可以点「继续」接着写。
- 如果换模型后仍然频繁中断，多半是网关 / 网络侧的问题，可以稍后重试或换一个模型。

## 章末复习

- 本章**所有知识点都学完**（所在段都收尾）后，章末复习自动解锁；不看掌握度。
- 复习课是独立会话：先列出本章知识点与各段交接，再和你讨论怎么复习（逐块回顾 / 出题 / 串体系）。
- 结论成型后，让助手把复习整理成《复习讲义》写入本章目录；生成后右栏工件分栏会打开，复习行变为「已生成讲义」。
- 历史讲义始终可打开；即使后来重学某个知识点，也不会删掉已有讲义。

## 右栏：进度 / 素材 / 支线

- **进度**：章 → 段列表 → 复习状态。点段打开该段；点复习行按解锁状态打开或提示。
- **素材**：
  - 顶部 `+` 登记文件 / 目录 / 网址；**没有大纲也能先登记**，此时只显示「未分配」；
  - `本段`：当前段确认的快照（有大纲并开段后显示）；
  - `本章`：本章分配（可取消分配；大纲生成后显示）；
  - `未分配`：已登记但还没分到当前大纲任何章的素材；
  - pdf / pptx / docx / 代码可填页码或行号区间后提取成可读 md。
- **支线**：保留「引用到主线」与「浮出」；**不再有「升格为正式会话」**。

## 要求（CONSTRAINTS.md）

要求与素材分开：考纲 / 老师统一要求写要求，不算素材。要求仍是四层：

- 全局：`AI教学/CONSTRAINTS.md`
- 本课程：`{工作区}/CONSTRAINTS.md`
- 本知识点：`{工作区}/{章号}·{知识点}/CONSTRAINTS.md`
- 本段：段文件夹内 `CONSTRAINTS.md`

段顶栏 / 复习顶栏的「要求」按钮打开四层抽屉；AI 每轮按「全局 → 本课程 → 本知识点 → 本段」注入，越靠后越细。

## 改大纲 / 删知识点

- 加章、改章名、加知识点、调顺序：对课程助手说，改动落到 `课程.md`。章行带稳定 ID（`## [c3] 章名`），重排不会把复习与素材分配错位。
- 删除知识点：没学过的可直接删；已学 / 学一半的，助手会先让你把这段对话整理归档，确认后才删。

## 不支持什么

- 课程结构只有「章 → 知识点」两级，没有三级。
- 一段只能覆盖**同一章**的知识点；同一章同时只允许一个进行中的段。
- 零散对话、场景模板、准备态、学习流画布、课时生命周期、支线升格都已删除。
- 进度 / 素材 / 复习解锁只看「是否学完」，不看掌握度分数。
