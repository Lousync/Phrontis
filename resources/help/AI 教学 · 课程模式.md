# AI 教学 · 课程模式

「课程模式」把 AI 教学的**工作区**从「文档文件夹 + 问答」升级为一门**有进度、可检验、可演进**的课。开启后，同一工作区获得课程大纲、课程主页、面向整门课的「课程助手」会话与按知识点记录的掌握度；**未开启的工作区维持原有自由问答**，两者按工作区共存、互不影响。

## 开启课程模式

在 AI 教学工作区顶栏、工作区标题右侧点「**开启课程模式**」，该工作区即变为一门课，随后落到课程主页。这是**按工作区**的开关，与工作区元数据一起保存；关闭后回到普通问答，原有素材与会话保留。

## 建课：生成课程大纲

工作区已开启课程模式但还没有大纲时，课程主页显示「**生成课程大纲**」。点开后选**大纲依据**，在向导里填「考纲名称」与「学习目标」，点生成：

- **官方考纲 / 教材目录** → 在文本框粘贴考纲或目录文字；
- **已有素材 / 提取稿** → 从本工作区已登记素材里勾选（默认全选；标「有正文」的素材会把正文一并交给 AI，只有清单的仅给名称）；
- **锚定 + 补充** → 文本框与素材勾选表都提供；
- **只有目标** → 都不填，按学习目标自由生成。

生成**流式进行**：过程面板实时显示模型输出与当前阶段（完成后自动收起，点标题栏「查看输出」可重看）。大纲为**两级：章 → 知识点**，每条知识点标注来源（考纲 / 素材 / AI 补充），粒度拆到「一个可独立讲解、可出题检验的最小概念」。结果进入「**编辑课程大纲**」，可增删、改字、调顺序，确认后点「**确认，进入课程主页**」。大纲以 Markdown 落在工作区内的 `课程.md`。

## 课程主页

课程主页按章（可折叠）列出知识点，每个知识点带状态（**未开始 / 学习中 / 待检验 / 已掌握 / 待复习**）、掌握度条与来源标注；顶部有「**继续学习**」。

## 上课与检验

点左栏「**课程大纲**」树中的知识点、或课程主页里的知识点，即开一节「**上课**」会话（顶栏分段从「课程主页」切到「上课」）。上课时输入区上方显示本课覆盖的知识点 chip。对某知识点点「**检验**」出题作答，结果写回进度：答错的题回流错题本，未达阈值的知识点标为「待复习」。生成过程中可直接写回当前知识点的掌握度。

## 课程助手

顶栏分段第三档「**课程助手**」是**面向整门课**的顾问会话，用于统筹规划、整理素材、知识点答疑。它可读课程大纲、进度与素材正文；**当前版本为只读，不落盘改文件**。整门课只有一个课程助手会话，**不计入课时与进度**。

## 修订大纲（AI 只增补）

课程主页点「**＋ 修订大纲**」打开抽屉。AI 先比对本工作区的素材快照（列出新增 / 已更新），再结合你补充的要求，产出**增补清单**（不是整份大纲）；勾选要采纳的条目后写回，**现有知识点与 id 一律保留**。

## 不支持什么

课程模式**不改变**工作区里的文件结构；大纲只有「章 → 知识点」**两级**，没有三级。课程助手当前**不能**代你改大纲或写文件——增补大纲走「＋ 修订大纲」。有大纲不等于已排课，开课始终由你点知识点触发。
