# AI 教学 · 课程模式

AI 教学的**整个工作区**就是一门「课」——不再有单独的「课程模式」开关。进入工作区后，与**教学助手**对话即可完成建课与学习：定学习目标、清点素材、生成课程大纲、按知识点上课与检验，进度自动沉淀。

## 对话驱动建课

1. 在工作区里**登记素材**（可选）。
2. 跟**教学助手**说你的学习目标。它会分析素材与目标。
3. 素材里若有 **pdf / pptx**，助手会先提醒你转写成 md（可在素材库对该素材做「提取稿」）。
4. 条件够了，助手会问「是否生成大纲」。你确认后，它先把**大纲草稿**放在对话里——不满意就继续跟它说，满意点「**正式生成**」落盘为 `课程.md`。
5. **分批**：先只展开**第一章**（正式开始本课程）；学完后对助手说「**展开下一章**」即可逐章往后加。目录素材较大时，助手会先**清点**（写 `SOURCES/{素材名}.index.md`：文件数 / 字数 / 是否已按子文件夹分类 / 待转写清单），再据此分章，避免整目录被截断。

## 课程主页

课程主页按章（可折叠）列出知识点，每个知识点带状态（**未开始 / 学习中 / 待检验 / 已掌握 / 待复习**）、掌握度条与来源标注；顶部有「**继续学习**」。

## 改大纲也是对助手说

素材或学习目标变了要更新大纲，同样是**对课程助手说**（课程主页右上角的「**改大纲（对助手说）**」按钮就是跳回对话）：加章说「展开下一章」；要删或调整知识点也在对话里说。

没有独立的「修订大纲」按钮或向导面板——大纲的产生与修改都由课程助手在对话里完成，改动落到 `课程.md`。

## 上课与检验

点左栏「**课程大纲**」树中的知识点、或课程主页里的知识点，即开一节「**上课**」会话（顶栏分段从「课程主页」切到「上课」）。上课时输入区上方显示本课覆盖的知识点 chip。对某知识点点「**检验**」出题作答，结果写回进度：答错的题回流错题本，未达阈值的知识点标为「待复习」。

## 章末复习课

每一**章末尾**都有一个「**复习课**」条目（与知识点并列、标注「章末」，**不计入**「x/9 已掌握」）。点它 → 进入一节**面向本章的课程助手会话**：助手会先列出本章知识点与掌握度，再和你讨论怎么复习（逐块回顾 / 出题检验 / 串成体系）。复习到一定阶段，让它**把结论整理成《复习讲义》落盘**（左栏有「生成复习讲义（对助手说）」按钮，也可直接说），写入本章目录 `{工作区}/{章号}·{章名}/复习讲义.md`；之后课程主页与左栏的复习课条目上会出现「**复习讲义 →**」入口。

复习课**不频繁**：每章一节，内容由你和助手**讨论得出**，不是自动生成的知识点级复习。

## 课程助手（顶栏第三档）

顶栏分段第三档是**课程助手**（课程主页里的引导文案也称它「教学助手」，指的是同一个会话）：**面向整门课**的会话，负责建课编排（清点 / 分章 / 生成·展开·改大纲 / 改删知识点）、整理素材与答疑。它可读课程大纲、进度与素材正文，并能**通过工具落盘**（生成大纲、删知识点、整理归档等）。整门课只有一个课程助手会话，**不计入课时与进度**；还没有大纲时也能直接用它。

它的文件夹固定在 `{工作区}/课程助手/`（**不带日期**、一个工作区一个），生成的产物（讲义 / 测验 / 思维导图 / 示意图、整理文档等）统一落在其下的 `output/` 目录；`.session.json`、`CONSTRAINTS.md`、`PROFILE.md` 等仍在夹顶层。其它会话（跟我学 / 深度研读等）仍按 `{MM-DD 会话标题}/` 命名，不受影响。

## 改 / 删知识点

改大纲、加章、删知识点都**对课程助手说**：

- **加章**：说「展开下一章」。
- **删知识点**：没学过的直接删；**已学 / 学一半的**，助手会先让你把这段对话**整理成一页并归档**（默认落 `output/`，也可指定目录——如「放在考研笔记 → 操作系统 → 对应章节」，助手会定位目录并告诉你**绝对路径**），你确认后才删除，避免丢学习记录。

## 收藏（钉住活文档随手翻）

学习过程中 AI 产出的文档分两类：**活文档**（跨课时、会持续扩充，如「操作系统英文缩写」速查表）与**课时/知识点总结**（讲义、交接、测验等，属于某个知识点，跟着课程结构走）。「收藏」只收前者——把跨课时的活文档**手动钉住**，在**左栏顶部一条「★ 收藏」细行**里随手翻到，不必每次去资源管理器里翻文件夹。

- **钉住**：资源管理器里**右键文件 → 「★ 钉到收藏」**；或回答里「✓ 已生成文档 →」旁的 **★** 按钮。再点一次即「取消收藏」。
- **查看**：左栏顶部「★ 收藏」行（**默认收起**，点一下展开；**没有收藏时整条隐藏**），点某条即在该文档打开（工件栏）。每条右侧 **✕** 可取消钉选。
- **助手能感知**：教学助手知道当前工作区收藏了哪些文档（清单会注入它的上下文），可回答「我收藏了哪些」或结合收藏给建议；**钉选 / 取消由你手动做**（助手不改收藏）。
- **持续扩充**：钉住只是「方便翻到」，不改文件本身。要补充内容，直接对 AI 说「把新的…加进这份速查表」，它会对**同一份**文档追加（不新开文件）。
- 收藏**按工作区分开**，存在仓库 `.knowbase/modules/aiTeaching/favorites.json`，随仓库走。

## 不支持什么

大纲只有「章 → 知识点」**两级**，没有三级。有大纲不等于已排课，开课始终由你点知识点触发。
