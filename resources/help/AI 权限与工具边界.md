# AI 权限与工具边界

AI 助手（右侧栏、工作台书签、AI 对话页共用会话）通过 63 个内置工具直接操作软件数据。本文说明它的能力范围、权限控制与操作边界。

## AI 设置分布在六个页签

路径：设置 → AI。该页共六个页签，一个页签一个域。**六页统一口径**：一行一件事 ——
行上只有「名字 + 一行摘要 + 控件」，解释在标签旁的 **ⓘ** 上（鼠标移上去、或 Tab 到它才浮出），
表单 / 账号 / 模型清单 / 场景分配 / 逐模型协议收进**折叠分组**（点开才有）。
所以「找不到某项」时先点开分组、把鼠标移到标签旁的 ⓘ 上 —— **能力没减，只是不再常驻**。

- **模型**：接入供应商与模型。供应商**一行一家**（名称 / 类型 / 账号与模型数 / 启停 / ⋯），**点开那一行就是编辑** —— API 密钥、名称、接口地址、协议类型、请求头、语义检索模型、账号列表、模型清单、逐模型协议都在展开区里，改完点保存。加供应商是右上角一颗「**＋ 添加供应商**」：选中预设后只差粘一个 API Key。**同一供应商可加多个账号**（各配各的 Key，换账号只切当前账号）。页面下方一个折叠分组：「**场景分配**」（就是"哪个场景用哪个模型"那张表，七个模型槽位，行上写「已指定 N / 7」）。**连通性测试三处入口**：端点行 ⚡ 测当前账号、账号行 ⚡ 测该账号、模型清单每行 ⚡ 测该模型（结果就地显示；平时不显示，划过该行才出，保存完会亮 3 秒）。
- **权限**：权限预设与逐模块读写档位、终端执行开关。九行并在一张卡里，每行「模块名 + ⓘ + 三档控件」。
- **工具**：五个折叠分组 —— MCP 服务器（N 个 · 已连接 M）、Skill 技能（N 个 · 已启用 M）、内置工具（N 项 · 只读，点开是可搜索的下拉）、最近调用（N 条审计记录）、高级（LibreOffice 路径 / 网页抓取）。MCP 与 Skill 的行操作在行尾的 ⋯ 菜单里。
- **对话**：四个折叠分组 —— 回复方式（流式输出 / 显示思考过程）、AI 助手（感知模式 / 深度思考 / 占用指示 / 上下文窗口 / 吉祥物）、编辑器续写、Agent 循环（推理轮数 / token 预算 / 历史上下文预算 / 压缩触发线 / 历史自动压缩）。
- **用量**：本月工具调用量与上限、模型 token 消耗。
- **教学**：产物根目录、删除会话时的文件夹处理。（**图片视觉转写模型不在这页**，它在「模型」页「场景分配」里。）

页签行右侧的「**复位**」把**当前页签**的设置恢复为默认值（点两次才生效）：只动本页签的项，**安全开关一律不参与**（终端执行、模块权限、仓库文件权限）—— 所以权限页上这个按钮是灰的，那是有意为之。

## 模型可以在哪几个地方指定

路径：设置 → AI → 模型 → 「场景分配」（哪个场景用哪个模型）里的七行。每行都是一个**可搜索的选择器**（按供应商分组，搜模型名或供应商名都能过滤，☆ 标记免费）：

- **对话默认模型**：AI 助手与 AI 教学的兜底；**AI 助手（侧栏）**、**长对话压缩摘要**：留空 = 跟随；
- **编辑器内联续写**：调用最频繁，建议单独指定快而省的模型；
- **图片视觉转写**：留空 = 自动挑一个支持图片的模型（按模型名判断）；
- **文生图**：`/生图` 用；**留空 = 报「未配置生图模型」**（图像模型没法靠名字猜，不自动挑）；
- **改图重绘**：改已有图用（需 image-edit / SeedEdit 类）；**留空 = 退化成按描述重画**，并在生图卡上标出。

**留空 = 跟随**：换了默认模型，留空的行跟着换；某行显式选过就固定不再跟随。
这张表治的是「三层作用域不可见」（本会话 ＞ AI 助手 ＞ 全局默认）—— 此前设置页只露最底层，
另外两处藏在助手面板与对话输入区，改了默认却发现某处没变时无从解释。
**另有一处不在这张表里**：每个对话自己的模型覆盖；批量改槽位（账号 ⋯ 的「将其他槽位改用此账号…」）不会动它。
选择器只列**可用端点**的模型（端点启用且至少一个账号可用），避免「选得到却调不通」。

## AI 能做什么

AI 内置 63 个工具（16 常驻、47 按需 —— 按需那批要 AI 申请后才进它的工具列表），按模块分组：

- 知识库：搜索页面；按 id 读取全文；新建页面；图谱拓扑体检（断链 / 孤岛页）；写 [[链接]] 前校验引用名。
- 博客日记：搜索日记；读取日记全文（按 id 或按日期直取当天）；新建日记（每天一篇）。
- 日程：按日期区间查询待办；创建、修改、删除待办。
- 习惯打卡：列出习惯与今日打卡状态；统计连续天数与完成率；按名称为今天打卡（幂等）。
- 番茄钟：统计近 N 天每日专注分钟与场次。
- 记账：导入手机 AI 生成的 JSON 账单（自动去重、自动建新分类与账户）；按区间查流水与合计；查账户与总额余额。
- 错题本：查询错题记录；按标签统计薄弱分布；写备注；打标签；加入分组；收藏；移除；按范围组卷出题。
- 情报：查询已抓取的情报条目（关键词 / 源 / 类型）；刷新左栏「AI 推荐」与列表筛选（这两个写动作只在 📡 情报助手的会话里可用，通用助手只读）。
- 仓库文件：列出目录；读取 .md/.txt 与文本类代码全文（.pdf/.pptx 提取文本）；按关键词搜索；新建、覆写、局部编辑；重命名或移动；移入回收站（可恢复）。
- 生图：按描述生成图片；带图路径时改为修改那张图。产物落 `.attachments/<年-月>/`，重名按 `-v2`/`-v3` 递增。用法与设置见《AI 生图》。
- 联网：搜索互联网（DuckDuckGo / Bing）；读取指定 https 网页正文（去导航与广告）。
- 软件自身：检索官方使用手册（用法问题会先查手册）；申请启用扩展工具（含插件提供的）。

## AI 能动我哪些数据

AI 可读写：知识库页面、博客日记、日程待办、习惯与打卡、番茄钟统计、错题本、记账流水与账户余额、仓库内文件（.md/.txt/文本类代码/.pdf/.pptx），以及互联网信息。情报池对通用助手只读（可查询；推荐与筛选的写动作在 📡 情报助手里）。数据 100% 存本机，AI 不上传；联网仅发生在你要求搜索或读网页时。读写档位逐模块设置，未配置的默认只读；记账默认读写（便于直接记入导入的账）；情报默认只读。

## AI 权限怎么设置

路径：设置 → AI → 权限。每个模块三档，用**分段控件**选择：

- 禁止：相关工具完全不出现在 AI 的工具列表中，AI 对该模块内容不可见。
- 只读：可查询、读取、统计，不能修改（未配置模块的默认档位）。
- 读写：可新建、修改、删除，全部留审计记录。没有写操作的模块（如番茄专注），这一档是灰的。

**权限预设**（同一页顶部三个按钮）：先选一个档位批量设好，再逐模块微调 ——
「最保守」= 全部只读（含仓库文件）；「日常」= 只读，但日程与记账可写；「完全信任」= 有写操作的模块全部可读写。
批量开启写入权限后，页面上会出现醒目提示：AI 的写操作将**直接生效**，不会逐次请求确认。统一助手仍可在会话里切「先预览」，把可暂存写入改成确认后应用；两条开关互不替代。

仓库文件另有独立的读/写开关。权限不足时 AI 不是调用失败，而是工具根本不出现在其工具列表中；AI 回复「我目前没有这个能力」属于权限限制的结果，并非模型能力不足。

## AI 什么时候能写

写类工具默认不在 AI 视野内（省上下文）。AI 要写时先申请，同意后本会话内持续可用；被拒（模块只读或禁止）时会说明「未执行」并指出该去哪个设置页调整。删除类操作要求先查询并确认目标 id 与标题一致，不凭记忆删除。

## AI 执行终端命令（builtin.terminal.exec）

这是 AI 唯一能运行系统命令的工具，默认**完全不开启**（开关：设置 → AI → 权限 → 终端执行；关闭时它不在 AI 的工具列表里）。开启后走四道门：本开关 → terminal 模块权限 → 支线会话硬拦 → **每条命令都在终端模块「AI 执行记录」里等你行内确认**（高危命令给严重警告，90 秒不确认视为拒绝）。执行固定在仓库根目录、默认 30 秒超时、输出自截。详见《终端》。

## AI 不能做什么

- 禁止模块的内容对 AI 完全不可见；AI 若详细描述其内容属无依据推测，应要求它调工具核实。
- `.knowbase` 内部结构化数据对 AI 只读，AI 不能绕过模块直接修改配置文件。
- 图片与超过 10MB 的文件拒绝读取；扫描版 PDF 提取不出文本属预期行为。
- 内网、私网、IP 直连的网页一律拒绝访问，仅支持 https。
- 文件删除进入回收站可恢复；重命名与移动不可自动回滚。

## AI 的操作有记录吗

每次工具调用均写入审计日志，在「设置 → AI → 工具」的「最近调用」分组里可查（默认收起，最近 10 条，含入参摘要与耗时、不含返回内容）。AI 回复**上方**有一行**过程摘要**（默认「过程 · 思考 Ns · N 个工具」），默认收起、点开才看完整的思考段与工具调用（失败的标红）；生成中过程会实时展开，不必等回复结束。写入类操作完成后，AI 会列出本次已改动 N 项，点条目可直接打开文件。

## AI 说改完了但界面没变

写盘成功后界面会自动刷新。没变说明写入未成功，常见原因是权限拦截：先看审计日志确认（别直接采信「已完成」），再去「设置 → AI → 权限」调整对应模块档位，要求 AI 重做。
