# 用量

「用量」是图标条上的**整窗模块**（图标是一只仪表盘），汇总本机**全部 AI 调用**的 token、估算费用与调用次数，并显示各供应商的**账户额度**。数据存在本机的 `ai-usage.json`（保留 400 天），只读、不上云、无账号。它和「设置 → AI → 用量」分工：设置里只管**月度工具调用上限**，明细与额度都看这里。

## 看板四块

顶部先选**时间窗**（近 30 天 / 近 90 天 / 近 365 天 / 全部）和**指标**（tokens / 估算费用 / 调用次数），右侧可切柱状与折线。往下依次是：

- **总消耗**：所选时间窗的 token 总量，按「未缓存输入 / 缓存读 / 缓存写 / 输出」四段拆开。悬停大数字看精确值。
- **估算费用**：按内置价目表折算的 USD，**不是账单**。若有些模型不在价目表内，会提示「实际费用为下限」。
- **调用次数**：有记账的天数也一并显示。
- **趋势**：时间窗内的柱状 / 折线；近 30 / 90 天按天，近 365 天按周，全部按月。
- **活动热力图**：固定回看近 365 天，颜色越深当天用量越大。
- **按供应商 / 模型拆分**：每行一个「供应商 · 模型」，列出调用数、四段 token、合计、估算费用与占比。点表头可排序。

「用量」覆盖对话、AI 教学、AI 助手、划词翻译与嵌入等**所有**走模型的地方；中途被叫停的任务，按其已经发生的调用计入。

## 账户额度

看板顶部是「账户额度」卡片区，数据来自供应商接口（打开时拉一次，也可点「刷新」）。它**与上方时间窗无关**，空数据时也照常显示。

- **一供应商一张卡**，卡内显示**当前激活账户**。DeepSeek 这类给的是**余额（钱）**；OpenCode Go 这类给的是**套餐窗口**（5 小时滚动 / 本周 / 本月，含百分比与重置倒计时）。
- 进度条颜色表示紧张程度：≥80% 变琥珀，≥100% 或被限速变红并标「限速中」。
- **多个账户**时，卡头显示「还有 N 个账户」，点开行内**懒查**其余账户的额度（只给一行概要，不画进度条）。
- **不提供余额接口的供应商不占卡**，会收成卡片区底部一行「另 N 家供应商未提供余额接口」，点「看名单」展开。
- 上游不上报计划名，所以只显示窗口与占比，不显示套餐名称。

## 对话内「本轮消耗」

每条 AI 回复的**末尾会有一行小字**：`↑输入 ↓输出 · 合计 tokens · $x 估算`。这是**本条回复**（含其中多轮模型调用）的合计；费用按内置价目表估算，**无价目时只显示 tokens、不显示金额**。AI 侧栏标题栏的用量气泡仍可点开，看今日与会话累计。

## 统计口径

- **缓存写**常为 0：多数上游不单独上报缓存写入量，未上报即记 0，界面已注明。
- **费用是估算**：按内置价目表折算，仅供比较，不等于供应商账单。
- **供应商名**：早期未带供应商的历史记录会显示为「默认通道」，不会伪装成某个供应商。
- 统一记账后，此前直连模型（翻译 / 嵌入 / 教学 / 内联建议）的调用也被计入，因此看板数字可能比旧版更大——这是**口径补齐**，不是多算。

## 不支持什么

- 不做定时轮询，也不做低余额提醒；额度需打开模块或手动刷新时更新。
- 不支持自定义或导入价目表，也不支持导出用量报表。
- 账户额度只查**当前激活账户**与手动展开的账户，不后台批量拉取。
