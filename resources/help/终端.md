工作台内置的真终端（Windows 默认 PowerShell，macOS/Linux 取系统默认 shell）。pty 在主进程运行,渲染层只做显示 —— 可以在里面直接跑 neovim / vim / htop 这类全屏交互程序,输入、配色、滚屏与真实终端一致。

## 打开与会话

1. 工作台左栏点「终端」书签打开;首次打开自动创建第一个会话
2. 会话条上「＋」新建（最多同时 4 个）、「✕」结束单个会话;左栏模块侧栏有同样的会话列表
3. 会话随标签页保活:切到其他模块再切回来,输出和滚动位置都在;关闭应用即全部回收（不持久化）

会话默认打开在**当前仓库根目录**（没开仓库则在用户主目录）,所以 `git status`、`nvim 笔记.md` 这类操作可以直接做。

## 在终端里用 neovim

直接输入 `nvim`（或 `nvim 文件.md`）即可,全屏界面原样呈现。两个注意点:

- nvim 需已安装并在 PATH 中（Windows 可 `winget install Neovim.Neovim`）;
- 用 nvim 改仓库里的 `.md` 笔记时,**不要动 frontmatter 里的 `id:` 行** —— id 丢了这篇笔记会退回「草稿」状态,从知识库列表消失。

## shell 选择

默认 `auto`:Windows 自动探测 pwsh 7(含标准安装目录),没有就用系统自带的 PowerShell 5.1;macOS/Linux 取 `$SHELL`。终端工具栏的 shell 牌显示当前实际值,版本号按系统实测(探测不到就只显示名字)。左栏底部的 shell/cwd 信息默认收起成 ⓘ,鼠标悬停展开。要固定某种 shell,改设置里的「终端默认 shell」（设置 → 搜索「终端」）,字号也在那里调。

**两种 Windows shell 的输入体验不同**:

- **PowerShell 5.1** 走控制台**原生输入**:敲什么显什么(和 cmd 一致),没有语法高亮和灰色历史预测。这是刻意为之 —— 5.1 自带的老版 PSReadLine 在中文输入下会重画出乱码,原生模式最稳;
- **PowerShell 7** 保留完整的现代行编辑(高亮、历史预测)。建议装一个(`winget install Microsoft.PowerShell`),装完重启应用即被自动识别,无需改设置。

## AI 执行记录

开启「设置 → AI 终端执行」后,AI 可以申请 `builtin.terminal.exec` 工具执行命令,规则如下:

- **每条命令都要你确认**:请求会以「待确认」行内卡出现在终端的「AI 执行记录」签页（角标脉动 + Toast 提醒,不弹窗不打断）,点「允许执行」才真正运行;
- **高危命令例外**:删除、格式化、强推等命中高危启发式的命令会弹红色严重警告窗 —— 这是全应用唯一允许中央弹窗的确认场景;
- **确认超时 90 秒视为拒绝**;AI 拿到的是被拒结果,会如实告知未执行;
- 执行在仓库根目录、无 TTY、默认 30 秒超时（AI 可指定最多 5 分钟）;输出留存近 50 条记录供回看。

关闭该开关 = 执行工具完全不进入 AI 的工具视野（AI 不知道它存在）。此外它还受「设置 → AI 工具 → 权限」里 terminal 模块权限的独立约束。

## 已知边界

- AI 执行没有 TTY,输出里没有颜色控制符,属预期;
- 高危启发式是「提醒」不是「沙箱」——复合命令可能绕过标记,真正的边界是你确认这一步;
- 终端不落盘、无持久化:关掉应用,会话与滚动历史一起结束。
