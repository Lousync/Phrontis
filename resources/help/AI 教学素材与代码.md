# AI 教学 · 素材与代码

3.14 起，课程素材只维护**一份** `.knowbase/modules/aiTeaching/sources.json`。它按工作区存放：

- **登记**：这份文件里有哪些素材（标题 / 类型 / 仓库相对路径 / 提取稿 / 轻量索引）；
- **章级分配**：每一章用哪些素材、各自哪个区间；
- **段级确认**：开段预检时把收窄后的区间快照写进 `progress.json`，之后改章级分配不影响已开的段。

AI 每轮只看到**本段确认的素材 / 本章已分配的素材 / 课程助手的登记摘要**，不会自动扫描整个 `SOURCES/`。

## 登记方式

- 右栏「素材」→ 顶部 `+`：填文件 / 目录 / 网址，可选显示名；仓库外文件会复制进 `{工作区}/SOURCES/`，仓库内文件只引用。
- **没有课程大纲也能先登记**：此时素材只进「未分配」；大纲生成后再按章分配。
- 在对话里让课程助手用 `course.sources.register` 批量登记。
- 目录素材登记后，助手可先用 `inventory` 清点（写 `SOURCES/{素材名}.index.md`），再按章分配。

旧版 `SOURCES/SOURCE.md`（工作区级 / 知识点级 / 旧课时级）会在第一次读取素材时**懒迁移**进 `sources.json`；原 `SOURCE.md` 不删不改，可回滚。

## 章级分配

- 课程助手用 `course.sources.assign` 把素材分到章；能判断区间就带页码 / 标题区间，判断不了就整章。
- 右栏「本章」可取消分配；「未分配」是已登记但还没分到任何章的素材。
- 分配只是计划；点知识点开段时仍会做一次**预检**：
  - 默认按目录 / 文件名 / 标题缩窄到本段选中的知识点（精确 / 缩窄）；
  - 匹配不到就回退本章分配区间（整章）；
  - 确认后写段快照。

## 区间：页码 与 行号

`pdf` / `pptx` / `docx` 用**页码区间**（如 `12-34`）；`code` 用**行号区间**（如 `100-250`）。右栏「提取」会按区间生成可读 md：`{素材名}-p12-34.md` / `{素材名}-L100-250.md`，写入素材同目录并回写 `extractRel`。提取稿**允许手工修正**，AI 后续按修正版引用。

扫描版 PDF / 图片型内容若文本层为空，需要视觉转写（旧版入口保留在主进程能力中，界面暂以文本层提取为主）。视觉转写用的模型在「设置 → AI → 模型 → 哪个场景用哪个模型」的「图片视觉转写」一行指定；留空则由系统自动挑选。

## 把代码当成教学素材

Python / JS / TS / C++ / Java / Go / Rust / HTML / SQL / Shell 等文本源码都能直接登记；工作区文件读取自带二进制探测、大小守卫与超长截断。

- **大文件请标行号区间**：数千行源码整读会挤占上下文，登记 / 提取时写 `100-250` 即可；
- **AI 引用代码走卡片**：代码块卡片右上角可一键复制纯代码、切换自动换行；超过 20 行自动折成前 12 行，点「展开全部」铺开；
- **教学闭环**：可让 AI 生成可运行的单文件示例，产物落在会话文件夹里。

## 会话产物放在哪

AI 在对话里产出的东西落在**本会话文件夹**里：讲义与报告在根层，示意图在 `visuals/`，思维导图在 `mindmaps/`，**教学对话生成的图片在 `outputs/` 目录**。左栏「资源管理器」挂在该目录上：点 `.md` / `.json` 在右栏阅读，点 `.html` 走渲染预览，点图片在工件栏看大图。

## 手改 sources.json 出问题时

`sources.json` 是机器维护文件；手改后如果路径失效，素材行会显示「异常」并保留标题，不会静默丢失。优先在右栏重新登记 / 分配，或让课程助手修正。
