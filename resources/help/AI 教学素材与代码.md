AI教学模块把「你手里的资料」统一登记成会话的**素材库**：每个对话对应仓库里一份 `SOURCE.md` 登记表，AI 每轮对话自动读到的是**登记表**（名称、位置、区间、提取稿路径），素材本体按需再用文件工具去读——所以登记本身不占对话上下文。

## 三种登记方式（同一解析与写入）

1. 右栏「素材库 → ＋ 素材」表单：类型、名称、地址/路径、区间、存放方式、备注；
2. 直接编辑 `SOURCE.md`（小节标题 `### 编号. 名称`，字段行 `- 字段: 值`）；
3. 在对话里让 AI 按模板格式登记。

「已入库」= 选文件后拷贝进会话素材夹（`SOURCES/{对话}/`），仓库内自包含；「仅引用」= 只记 URL 或仓库/绝对路径，不复制。

## 区间：页码 与 行号

`pdf` / `pptx` 用**页码区间**（如 `12-34`），提取时只喂这些页；`code`（源码）用**行号区间**（如 `100-250`），提取稿按行区间截取，与页码同一机制、零新概念。

## 把代码当成教学素材

Python / JS / TS / C++ / Java / Go / Rust / HTML / SQL / Shell 等文本源码都能直接登记——工作区文件读取自带二进制探测、大小守卫与超长截断，坏编码另有兜底，无需任何额外配置。

使用注意：

- **大文件请标行号区间**：数千行的源码整读会挤占上下文，登记时写 `L100-250`（或 `100-250`）这段区间即可；
- **AI 引用代码走代码块**：回答中的代码以围栏代码块呈现，对话流与阅读视图都可直接复制；
- **教学闭环**：可让 AI 生成**可运行的单文件**示例（HTML/JS 无需运行时；Python 可要求它同时给出「预期输出对照」），产物落在会话文件夹里，与讲义、测验报告同区管理。

## 提取稿与手工修正

「提取」把区间内容转成 Markdown 稿（`{素材名}-p12-34.md` / `{素材名}-L100-250.md`），提取稿**允许手工修正**，重跑提取时会保留顶部手工修正头。扫描版 PDF 还可用「👁 转写」走视觉模型逐页转写（结果追补进提取稿，不覆盖原文本层）。

## 手改登记表出问题时

右栏会在检测到形状不规范时给出提示（如「N 个小节缺『编号.』未登记」），点开 SOURCE.md 修正即可——坏数据不会被静默丢弃却查不到。
