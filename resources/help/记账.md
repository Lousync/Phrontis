# 记账

记账是工作台内的模块，入口在左栏书签「记账」。数据保存在当前仓库的 `.knowbase/modules/accounting/` 下，只存本机，不上云、无账号。录入以 AI 为主要通道，也支持手动记一笔。

## 记一笔（手动）

打开左栏书签「记账」后，右栏出现「记账」面板（该面板仅在记账模块激活时显示）。在面板顶部填写：

- 类型：支出 / 收入。
- 金额（元，正数）与日期（默认今天）。
- 分类：餐饮 / 交通 / 购物 / 学习 / 居住 / 娱乐 / 医疗 / 人情 / 生活费 / 工资 / 奖金 / 其他。
- 支付方式：即账户，默认 微信 / 支付宝 / 银行卡 / 现金。
- 商户 / 对象、备注（可选）。

填完点「保存」。中央「流水」视图按日分组显示，每笔右侧铅笔可编辑、垃圾桶可删除。左栏侧栏可按月份与分类筛选。

## 用手机 AI 生成 JSON 批量导入

花销或收入发生后，把这句话告诉手机上的 AI（如 DeepSeek），让它按固定格式输出一段 JSON；回到 Phrontis 一次性导入多笔。

JSON 最少两个字段：`amount`（金额，正数）与 `type`（`expense` 支出 / `income` 收入）；`date` 省略按当天；`category` / `payment` / `merchant` / `note` 可省略。示例：

```json
{ "version": 1, "transactions": [
  { "date": "2026-10-05", "type": "expense", "amount": 28.5,
    "category": "餐饮", "payment": "微信", "merchant": "沙县小吃", "note": "午饭" }
] }
```

两条导入通道，结果一致，重复条目自动跳过：

- 本地解析：右栏「记账」面板底部「导入手机 AI 的 JSON」，粘贴或拖入 `.json` 文件 →「解析预览」→「确认导入」。
- 交给 AI 助手：把 JSON 粘给右栏 AI 助手对话，AI 调用记账工具写入。

固定格式的完整指令模板：右栏「记账」面板点「手机端指令模板」，复制给手机 AI。导入时遇到没见过的分类名或账户名会自动创建。

## 余额

账户即支付方式。每个账户的当前余额 = 初始余额 + 累计收入 − 累计支出，随记账自动更新；初始余额可在「统计」视图的「账户余额」区域直接修改。总余额 = 各账户当前余额之和。

余额默认隐藏，显示为 `••••••`。点余额旁的眼睛按钮可在显示余额与隐藏余额之间切换；流水顶栏的「总余额」与统计页「账户余额」表头的眼睛联动。该显隐状态不跨启动保存，每次打开软件默认隐藏。

「统计」视图的「账户余额」区域可点「添加账户」新建自定义账户（如 校园卡）并设置其初始余额。没有选择支付方式的流水归入「未指定」，不计入任何账户。

## 统计与复盘

- 统计：本月支出 / 收入 / 结余、支出分类占比、近 6 月收支。
- 复盘：复盘视图把周 / 月 / 年入口跳转到博客模块对应的总结文档，总结的统计块自动包含「本期支出 / 本期收入」。记账不另存复盘文件。

## AI 与权限

记账的 AI 工具默认授权为读写，可直接记入 AI 导入的账。工具：`accounting.import-json`（导入 JSON）、`accounting.query`（区间查流水与合计）、`accounting.balances`（账户余额与总额）。档位在 设置 → AI 工具 → 权限 → 记账 调整。

## 不支持什么

- 不支持账户间转账、预算与超支提醒、多币种换算；金额按单一货币记账。
- 余额的「隐藏」只是界面显示处理，不改变数据本身。
- 删除一笔流水是直接删除，不进回收站。
- 分类与账户只可新增，暂不支持重命名或删除。
