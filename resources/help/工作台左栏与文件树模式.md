# 工作台左栏与文件树模式

工作台左栏有**总览**（书签列表）、**文件树模式**（仓库文件树）与**模块侧栏**（点书签后该模块的侧栏）三种形态，三者互斥，同一时刻只显示其中一种。

## 怎么进入文件树模式

总览态左栏头部有三个图标按钮，第三个是「切换为文件树模式」，点它左栏换成仓库文件树；再点它或树头的「返回总览」按钮回到总览。从总览点任一书签、或从图标条切模块，都会退出文件树模式——进入模块即视为放弃树模式。

## 树头的四个按钮

文件树头部从左到右四个图标按钮：**返回总览**、**排序方式**、**展开 / 收起此目录（含子目录）**、**目录聚焦**。

- **排序方式**：名称 A→Z（默认）、名称 Z→A、修改时间（新→旧）、修改时间（旧→新）。目录恒排在文件前面，四种方式都不改变这一点。选择会记住，下次打开还是这一种。
- **展开 / 收起**：在树里选中某个目录时，展开或收起该目录**连同它下面的所有子目录**；没有选中目录时，「展开全部（含子目录）」作用于整棵树。
- **目录聚焦**：只显示当前打开文件所在的目录链与同级项；点骨架条退出聚焦并定位。

## 文件树能做什么

- 点目录行**展开 / 折叠**，逐层浏览仓库里的真实目录与文件；
- 点文件**打开为编辑页签**，直接进入编辑态（不是先阅读）；
- **拖拽**条目到别的目录即移动；
- 空白处或条目上**右键**打开菜单（见下节）。

新建知识页会写入 frontmatter `id` 并**立刻打开**，写完保存即被知识库收录。

## 打开非 Markdown 文件会看到什么

非 `.md` 文件也会出现在树里，点开后按类型落点：

- **PDF** → 内嵌阅读器（与书架同一套：三模式、翻页、缩放、目录、划词摘录）；
- **文本类**（代码 / `txt` / `json` / `csv` / 日志 / 配置）→ 直接进可编辑页签，超过 10 MB 的以只读方式打开并给出提示条；
- **HTML** → 沙箱渲染整页；
- **图片**（`png` / `jpg` / `jpeg` / `webp` / `gif` / `bmp` / `svg` / `avif`）→ 内嵌图片查看器（见下节）；
- **其它二进制、超过 50 MB 的文件** → 只给一张文件信息卡（在系统中打开 / 在文件夹中显示）。

二进制内容不会以乱码形式显示出来。非 Markdown 文件保存的是原始字节，**不会被写入 frontmatter**。

### 看图片

图片在笔记区直接渲染，工具栏就在顶栏右侧（图片态下那里本来就只剩 `⋮`，所以不占额外一行）：

- **适应窗口**是默认，比窗口小的图**不会被放大**（64×64 的图标就显示 64×64）；还有**适应宽度**与**实际大小 1:1**；
- `Ctrl` + 滚轮缩放，**以光标为锚点**（光标下那个像素不动，方便对准细节）；拖拽平移；**双击**在「适应窗口 ⇄ 100%」之间切换；
- 左右旋转 90°；放大到 4 倍以上自动切成最近邻，凑近看像素不会被插值糊掉；
- 快捷键（**无修饰键**）：`0` 适应窗口、`1` 实际大小、`[` 向左旋转、`]` 向右旋转；
- 透明区域会铺出**棋盘格**底（`png` / `gif` / `webp` / `svg` / `avif`；`jpg` / `bmp` 格式上就没有透明通道，用纯色底）；
- `⋮` 里另有一份「查看」组（适应窗口 / 实际大小 / 向左旋转 / 向右旋转），以及 **SVG 的「看源码」**——可以切到编辑器直接改 XML，再切回来看渲染。

图片打不开时会给一张说明卡，而不是一片空白：

- **读取中**——大图先显示「正在读取图片 · 大小」，读完自动换成图或下面两种卡；
- **图片过大**——超过 32 MB **或** 1 亿像素（后者不是前者的补充：压缩后只有几 MB 的图，解码成位图可能占几 GB 内存）；
- **图片解码失败**——文件头能读出尺寸，但图像数据解不开（文件损坏，或扩展名与实际格式不符），可以点「重新读取」。

后两种卡都带「在系统中打开」与「在文件夹中显示」。

### 顶部那条栏

所有非 Markdown 文件（**思维导图除外**——它自带一条工具条）在正文上方都有一条和 Markdown 笔记一样的顶栏：

- 左端 `← →` 是**页面访问历史**（后退 / 前进，`Alt+←` / `Alt+→`）；
- 中段是**文件名**；PDF 还会在后面多一个「N 页」，**图片**多一个「宽 × 高」像素尺寸；
- 中段的绿点 = **保存状态**，只在真的能保存的类型上出现：**Markdown 笔记**、可编辑的代码 / 文本、HTML 源码态、SVG 源码态；
  PDF、图片、二进制、以及超过 10 MB 以只读打开的文本都不显示绿点；
- 右端 `⋮` 是**更多操作**：md 与非 md 都有**重命名 / 创建副本 / 将文件移动到… / 复制路径 ▸（相对 / 完整）/ 在文件列表中显示 / 在系统中打开 / 在文件夹中显示 / 删除**（md 另有查找替换与分屏）；
  非 md 另有 **文件信息**（路径 / 大小 / 修改时间），HTML 与 SVG 多一项 **看源码 / 看渲染（图片）**，`txt`、HTML 与图片多一项 **沉浸阅读**。
- 图片态下 `⋮` 左侧还有一组**缩放与旋转控件**（缩小 / 百分比 / 放大 / 适应窗口 / 适应宽度 / 实际大小 / 左右旋转）。

PDF 阅读器自己那条栏只保留阅读控件（模式切换 / 翻页 / 适配与缩放 / 大纲 / 搜索 / 书签 / 护眼 / 沉浸 / 缩放百分比）——
书名与页数已经上移到顶栏，不会上下各显示一遍。

PDF 点「沉浸」后**顶栏也会一起隐藏**，正文占满窗口；按 `Esc` 退出沉浸、顶栏回来。

非 Markdown 文件的动作全部收在这条顶栏的 `⋮` 里（行内渲染，分屏时两栏各挂各的）。

## 右键菜单有哪几项

菜单按**右键点在哪**分三套，口径与 Obsidian 一致 —— 「新建 / 粘贴」只给**文件夹与空白处**，
**文件条目上只有「对这个文件做什么」**：

- **文件上右键**：
  - **打开**（知识库文件树）/ 直接点开（工作台文件树）
  - **创建副本**、**将文件移动到…**
  - **复制路径**（二级：**仓库相对路径** / **完整路径**）
  - **使用默认应用打开**、**在系统资源管理器中显示**
  - **重命名**、**删除（回收站）**
- **目录行上右键**：**新建文件**、**新建文件夹**、**新建知识页**、**粘贴系统剪贴板**（都落在该目录内）+
  **展开此目录（含子目录）**、**收起此目录**、**重命名**、**删除（回收站）**；
- **条目下方的空白区域右键**：**新建文件**、**新建文件夹**、**新建知识页**、**粘贴系统剪贴板**（四项都落在仓库根目录）。

**两棵树的文案差异**：知识库侧栏那棵用 **新建目录** / **新建分类目录** / **粘贴** / **删除**；工作台文件树用 **新建文件夹** / **新建知识页** / **粘贴系统剪贴板** / **删除（回收站）**。文件条目上都是同一套「对这个文件做什么」，只差知识库树多一项**打开**。

**创建副本**按字节复制出新文件，名字是「主名 副本.扩展名」（重名自动加序号），文本与二进制文件都能正确复制；只支持文件，在文件夹上点会提示「暂不支持复制文件夹」。

**将文件移动到…**点开是一个**带输入框的目录列表**：输入目录名即时筛选，`↑↓` 选、`Enter` 确认、`Esc` 取消；目录过多时底部会明说「已截断到 2000 个」，不会静默少列。
列表里**不会出现文件当前所在的目录**（移过去等于没移），目录自己右键时也**不会出现它自己和它的子目录**（移进去会成环）。
在**工作台文件树**里，它和拖拽移动是同一件事的两种做法，都会进撤销栈。

**复制路径**走系统剪贴板；**使用默认应用打开**用系统默认程序打开该文件，**在系统资源管理器中显示**则是打开所在文件夹并选中它。

## 从系统资源管理器改了文件，软件里会自动更新

在仓库里用外部程序新建、改名、删除文件后，文件树**约 1 秒内自动跟上**，不需要切模块或手动刷新。

知识库列表与搜索索引同样自动重建；刚改完没出现就稍等片刻。

## 文件树不显示软件生成的文件

树里默认**不展示**软件自己的产物目录（如 AI 教学的素材目录、`.ignore` 等软件文件），这是有意设计：文件树用于浏览你自己的笔记，软件生成物属于噪音。它们仍在磁盘上，用资源管理器可见。

## 常见误用

- 在文件树里右键空白处却点了没反应 → 确认点的是树区域内部，不是左栏头部或底部；
- 以为文件树删了文件就被彻底删除 → 删除一律进**回收站**模块，可随时找回；
- 在文件树里找不到某个目录 → 可能被 `.ignore` 规则隐藏，或被当成软件文件收起了；
- 以为在左栏能编辑正文 → **左栏只负责浏览与文件管理，不能写正文**；编辑一律在中间区的编辑页签里。
