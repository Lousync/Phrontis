# 工作台左栏与文件树模式

工作台左栏有三种形态：**总览**（书签列表）、**模块侧栏**（点书签后该模块的侧栏）、**文件树模式**（仓库文件树）。三者互斥，同一时刻只显示一种。

## 怎么进入文件树模式

总览态左栏头部有三个图标按钮，第三个是 🌳「切换为文件树模式」。点它左栏换成仓库文件树；再点它（或点树头上的 🏠）回到总览。

从总览点任一书签、或从活动栏切模块，都会**退出文件树模式**回到模块侧栏——进入模块即视为放弃树模式。

## 文件树能做什么

- 点目录行**展开 / 折叠**，逐层浏览仓库里的真实目录与文件；
- 点文件**打开为编辑页签**，直接进入编辑态（不是先阅读）；
- 空白处或条目上**右键**打开菜单：新建文件 / 新建文件夹 / 新建知识页 / 粘贴系统剪贴板 / 重命名 / 复制路径 / 删除（回收站）；
- **拖拽**条目到别的目录即移动；
- 树头上的**准星按钮**开启目录聚焦：只显示当前打开文件所在的目录链与同级项，点骨架条退出聚焦并定位。

新建知识页会写入 frontmatter `id` 并**立刻打开**，写完保存即被知识库收录。

## 空白处右键新建：点哪里都行

条目下方的空白区域与条目本身一样可右键，弹出的都是同一套菜单。空白处右键时「新建」落在仓库根目录；目录行上右键时落在该目录内。

## 从系统资源管理器改了文件，软件里会自动更新

用 Windows 资源管理器（或任何外部程序）在仓库里新建、改名、删除文件后，文件树**在约 1 秒内自动跟上**，不需要切模块或手动刷新。

知识库列表与搜索索引同样会自动重建。若刚改完没立刻出现，稍等片刻即可。

## 文件树不显示软件生成的文件

树里默认**不展示**软件自己的产物目录（如 AI 教学的素材目录、`.ignore` 等软件文件），这是有意设计：文件树用于浏览你自己的笔记，软件生成物属于噪音。它们仍在磁盘上，用资源管理器可见。

## 常见误用

- 在文件树里右键空白处却点了没反应 → 确认点的是树区域内部，不是左栏头部或底部；
- 以为文件树删了文件就被彻底删除 → 删除一律进**回收站**模块，可随时找回；
- 在文件树里找不到某个目录 → 可能被 `.ignore` 规则隐藏，或被当成软件文件收起了；
- 以为在左栏能编辑正文 → **左栏只负责浏览与文件管理，不能写正文**；编辑一律在中间区的编辑页签里。
