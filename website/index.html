什么是双链
更新于今天 · 被 12 篇笔记引用 · 双链笔记法 / 第 1 章

双链的核心是让每条笔记成为网络中的一个节点：写作时通过 [[]] 引用其他笔记，被引用的笔记会自动积累反向链接。

为什么反链重要

安全设计

本地优先不等于安全松懈——每一层都有明确防线

数据本地 + 系统级加密

数据 100% 本地存储；密码本列使用 Windows DPAPI 加密，复制的密码 30 秒后自动清空剪贴板。

渲染进程沙箱

Electron 沙箱 + contextIsolation，IPC 最小暴露面，路径操作防穿越（Zip Slip 防护）。

AI 权限分级

API Key 系统级加密、渲染层永不可见；工具按模块禁止 / 只读 / 读写分级，未授权工具对 AI 完全不可见；MCP 外部命令双重确认。

内容渲染安全

Markdown 默认不渲染原始 HTML，无 XSS；AI 生成的 HTML 产物经自定义协议沙箱渲染，响应头 default-src 'none'。
