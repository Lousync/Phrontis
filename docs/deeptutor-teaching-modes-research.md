# DeepTutor 教学模式调研（「对话」模式设计输入）

- 日期：2026-11-23
- 调研对象：HKUDS/DeepTutor（`main`，v1.7.4 时代）
- 用途：为 AI 教学「对话」模式（不建课、单份资料 / 单题辅导）提供设计依据
- 关联：`docs/ai-teaching-right-viewer-unify-plan.md`（右侧查看器统一是「对话」模式复用活动区的前提）

> 本文只保留结论与可直接落地的设计，不搬 DeepTutor 的功能全集。
> 调研方法：浅克隆仓库读源码与 prompt、官方文档、arXiv v3 论文；未运行产品。

## 一、结论先行

1. **确认对象**：港大数据智能实验室 HKUDS/DeepTutor，Apache-2.0，官网 `deeptutor.info`，论文 arXiv:2604.26962。另有一批同名小项目，不在本次范围。
2. **它的“模式”不是一堆功能页，而是“一个 agent loop + 可切换能力 + 共享资料与学习者记忆”**。Chat / Solve / Quiz / Reading / Mastery / Books 共用会话、知识库、画像和工具，每轮只决定“用什么流程、拿哪些工具”。
3. **最值得借鉴的四个形态**：Chat、Ask Questions、Solve、Reading。
4. **Phrontis 的短板不是教学动作不够，而是“单份资料 / 单题”的入口被课程挡住了**。素材、段会话、题单、错题、右栏查看器都已存在，缺的是“不建课也能开始”的容器。
5. **「对话」模式应当把这四种形态做成同一个会话里的四种能力**，而不是四个独立入口或 12 项能力菜单。
6. **最不该照搬**：Books 教材批量生成、多代理编排、Trace Forest 级记忆、硬掌握闸门、IM 陪伴 / 音视频生成。

## 二、四个要借鉴的形态

### M1 Chat（默认对话）

| 项 | DeepTutor 做法 | Phrontis「对话」采用 |
|---|---|---|
| 入口 | Home → Chat，无课程、无知识库也能用 | 「对话」模式默认形态 |
| 输入 | 文本、图片、PDF/Office/Markdown、网页、知识库、历史会话 | 文本、图片、单份资料；资料随会话保留 |
| 流程 | 单 agent loop：读上下文 → 直接答或调工具 → 再答；可中途 `ask_user` | 直接答；需要澄清时自动切到 Ask Questions 协议 |
| 产出 | 回答、笔记、生成文件/图片 | 回答；可整理成笔记（会话夹 `对话/{日期 标题}/`） |
| 记忆 | 按会话持久，粘性上下文 | 按会话持久；每个会话一个文件夹 |

**关键取舍**：教学风格不复制成多个模式，而是一层可复用的“辅导方式”（提示优先 / 直接讲解 / 苏格拉底），挂在输入卡上。

### M2 Ask Questions（先问后答）

| 项 | DeepTutor 做法 | Phrontis「对话」采用 |
|---|---|---|
| 触发 | composer 选 `Ask Questions` | 手动选「先问我」；或自动判定“需求不清”时触发 |
| 流程 | 本轮强制先调用一次 `ask_user`（1–4 个高信息量问题，选项卡 + 自由输入），不写前置说明；拿到答案后同一轮继续 | 复用现有 ```ask 围栏与提问卡；一次最多 1 个问题块，避免问卷化 |
| 边界 | 禁止重复用户已答过的问题 | 同一会话记住已答，不重复问 |
| 产出 | 更贴合约束的回答 | 同上 |

**它不是苏格拉底教学**，而是“澄清式前置”。在「对话」模式里适合做**首轮问诊**：先问“你卡在哪一步 / 想听到哪一层 / 有没有试过什么”，再决定讲法。

### M3 Solve（作业辅导）

| 项 | DeepTutor 做法 | Phrontis「对话」采用 |
|---|---|---|
| 触发 | 手动选 Solve；可附图、可挂知识库 | 附图 / 题干时自动判定；或手动选「解这道题」 |
| 流程 | 强制先出 2–6 步计划 → 逐步执行 → 每步记录结论 → 卡住重规划 → 完整答案 + 解析 | **提示阶梯**：先问卡点 → 一级提示（方向）→ 二级提示（关键步骤）→ 完整解 + 考点 + 易错点 |
| 工具 | 代码执行、GeoGebra 重建几何题 | 暂不做 GeoGebra；数学公式走 KaTeX |
| 产出 | 分步解、图、代码结果 | 分步解；2 道变式（```quiz 围栏）；一键加入题单 / 错题本 |
| 记忆 | 单会话，无课程记忆 | 单会话；错题回流沿用现有链路 |

**重要差异**：DeepTutor 默认直接给完整解，“提示优先”只是 starting prompt。Phrontis 应把**提示优先做成硬协议**，并给一个显式「直接给答案」出口，避免用户被吊着。

### M4 Reading（单份资料伴读）

| 项 | DeepTutor 做法 | Phrontis「对话」采用 |
|---|---|---|
| 入口 | Learning → Immersive Reading；先建 collection、打开至少一份 material | 右侧查看器打开文件即可；不建 collection |
| 输入 | 当前文档 / 选中段落 / 问题 | 当前文件 + 当前页 / 选中文本 |
| 流程 | 打开前先按问题预检索当前文档 → 用 outline/search/read 定位 → 没读到不许说 → 引用带 `[p.12]` / 时间戳 | **当前页文本注入** + 引用带页码 / 小节；没读到原文时明确说“这是通用解释” |
| 交互 | 引用段落 → `reader_goto` 滚动高亮；可 `reader_annotate` 标注导出 | 第一版只做 `[p.N]` 文本引用；跳转高亮与标注放第二版 |
| 产出 | 有页码的讲解、标注、笔记 | 讲解、笔记；可整理成文档 |

**关键设计**：文档不建索引、按页/章节存 unit，换来“每个命中保留精确 locator”。Phrontis 的右栏查看器已经具备阅读面，缺的是“当前页 → 对话上下文”这一层。

## 三、四种形态如何在同一个「对话」里共存

核心原则：**一个会话、一个输入框、四种能力按轮切换**。不做四个模式页，也不做 12 项能力菜单。

```
┌ 对话模式 ───────────────────────────────────────────────┐
│ 左：会话列表（对话/{日期 标题}/）                          │
│ 中：消息流 + 输入卡                                        │
│     ┌──────────────────────────────────────────────┐     │
│     │ 资料 chip：作业-第3题.jpg · 当前第 2 页          │     │
│     │ 方式：[自动] [讲解] [解题] [先问我]              │     │
│     │ 输入框…                              [发送]     │     │
│     └──────────────────────────────────────────────┘     │
│ 右：查看器（网页 / 笔记 / 电子书 / 旁问 / 文件）            │
└──────────────────────────────────────────────────────────┘
```

### 3.1 方式选择

- 输入卡上方一枚 `方式` chip，五档：**自动 / 对话 / 讲解 / 解题 / 先问我**。
  - 自动：按上下文路由（见 3.2）；
  - 对话：强制普通问答（Chat）；
  - 讲解：强制资料伴读（Reading）；
  - 解题：强制作业辅导（Solve）；
  - 先问我：强制先澄清再回答（Ask Questions）。
- 默认「自动」；每轮发送后回到自动（不粘住），避免用户忘了自己开过什么。
- 后续可在会话设置里提供「本会话默认方式」，第一版不做。

### 3.2 自动路由（自动档）

| 条件 | 走哪个能力 |
|---|---|
| 附图 / 题干明显是题目（“求…”“证明…”“这道题…”） | Solve |
| 右侧查看器打开了文件，问题指向“这页 / 这段 / 这份资料” | Reading |
| 需求含糊、缺少关键约束（“帮我弄一下这个”） | Ask Questions |
| 其它 | Chat |

自动路由只决定**首轮**；用户随时可以点 chip 覆盖。路由结果不弹提示，避免多一层确认。

### 3.3 四种能力的输出形态

- **Chat**：普通回答；底部动作「整理成笔记 / 以此建课」。
- **Ask Questions**：一张 ```ask 卡；用户答完自动继续原请求，不另起一轮。
- **Solve**：可折叠的「解题步骤」卡（计划 / 每步结论），最后给答案；底部「加入题单 / 加入错题本 / 再来两道变式」。
- **Reading**：讲解正文带 `[p.N]`；底部「打开当前页 / 整理成笔记」。

### 3.4 会话与资料

- 一个会话 = 一个文件夹：`AI教学/对话/{MM-DD 标题}/`。
- 资料随会话保留，不登记进课程 `SOURCES`；删会话按设置处理文件夹。
- 右侧查看器是资料面：打开的文件自动成为“当前资料”；用户选中文本时，选区进入下一轮上下文。
- 会话列表按 今天 / 昨天 / 更早 分组；可搜索、可重命名、可删除。

## 四、「对话」模式容器（入口与布局）

- **入口**：AI 教学「选择工作区」页新增「对话」入口（两种候选形态，原型确认）：
  - A：搜索框右侧、`+ 新建工作区` 旁一枚次级按钮；
  - B：工作区列表下方一条整宽入口条。
- **布局**：外层保留应用活动栏；内部三栏 = 会话列表（约 248px）+ 聊天 + 右侧查看器（可开关、可全屏）。
- **没有**：课程大纲、章节、开段预检、课程进度、章末复习、结课流程。
- **有**：多会话、会话文件夹、资料附件、右侧活动区、题单 / 错题回流、整理成笔记。

## 五、辅导协议（写进 prompt 的硬规则）

### 5.1 默认：提示优先（Solve）

1. 先问一句“你卡在哪一步？”（用户说“直接给答案”则跳过）。
2. 一级提示：方向 / 该用哪个知识点，不给答案。
3. 二级提示：关键步骤或公式。
4. 完整解：步骤 + 考点 + 易错点。
5. 变式：2 道同类题，写 ```quiz 围栏；题号重排 1..N。
6. 用户可一键「加入题单 / 加入错题本」。

### 5.2 讲解协议（Reading）

1. 先给三句地图：这份资料讲什么、结构、先知道什么。
2. 问“想从哪层听：直觉 / 推导 / 例题 / 考点”（可跳过）。
3. 每次只讲一层，讲完给一个检查问题。
4. 引用资料带页码 / 小节；没有定位时说“这是通用解释，不是原文”。

### 5.3 澄清协议（Ask Questions）

- 最多 1 个 ```ask 块，2–6 个选项，允许自由输入。
- 不问已经答过的问题；答完在同一轮继续原请求。
- 不问“要不要继续”这类低信息量问题。

## 六、资料上下文（第二层能力）

第一版（必须）：
- 右侧查看器打开文件后，把**当前页文本**（PDF / EPUB / TXT）或**当前选中段落**注入下一轮对话。
- 提示词要求：引用原文时带 `[p.N]` 或 `[小节]`；没有读到原文就明说。
- 上限：当前页 ≤ 3000 字，超出截断并提示“只读了本页前 3000 字”。

第二版（可选）：
- 点击 `[p.N]` 跳到查看器对应页并高亮。
- 划词 → 「问这段」；答案可回引到主线。
- 标注 / 高亮持久化。

## 七、MVP 分批

### 第一批：容器 + 默认对话（可独立上线）

- 选择工作区页「对话」入口。
- 会话列表（新建 / 切换 / 重命名 / 删除 / 搜索）。
- 会话文件夹 `AI教学/对话/{日期 标题}/`。
- 聊天 + 附件（图片 / 文件）+ 右侧查看器复用。
- 默认 Chat；「先问我」可用。
- 不做课程进度、不进课程统计。

### 第二批：Solve + Reading

- 方式 chip 五档（自动 / 对话 / 讲解 / 解题 / 先问我）+ 自动路由。
- 提示阶梯、解题步骤卡、变式题、加入题单 / 错题。
- 当前页文本注入 + `[p.N]` 引用。
- 讲解协议（三层地图 / 分层讲 / 检查问题）。

### 第三批：增强

- `[p.N]` 跳转高亮、划词问、标注。
- 「以此建课」升格到课程助手（预填 goal + 材料）。
- 会话默认方式、提示优先 / 直接讲解的偏好记忆。
- 诊断小测（5–8 题 → 弱项 → 建议从哪开始）。

## 八、不照搬清单

| 不搬 | 原因 |
|---|---|
| 12 项能力菜单 | 认知负荷高；入口应顺着任务走 |
| Books 教材批量生成 / typed blocks | 需要新渲染器与长任务管线，不是教学闭环瓶颈 |
| 多代理编排（规划 / 讲解 / 出题 / 批改各一个 agent） | 成本远大于收益；最多把“出题”和“校验”拆两次调用 |
| Trace Forest 级记忆 | 已有画像 / 交接 / 错题 / 会话历史，另做一套是另一个量级 |
| 硬掌握闸门 | 必须允许学生声明“我会了”，否则卡死 |
| IM 陪伴 / 播客 / 视频课 | 与本地优先、轻量目标冲突 |
| GeoGebra 图形重建 | 依赖重、边界多；数学需求强烈时再做 |
| 仿真卷（试卷 PDF 解析） | 抽取质量不稳定；先做“按知识点出题” |

## 九、验收口径（「对话」模式）

- [ ] 从选择工作区进入「对话」，不要求建课 / 大纲 / 章节。
- [ ] 新建会话后出现 `AI教学/对话/{日期 标题}/` 文件夹；切换会话内容互不串。
- [ ] 附件图片 / PDF 后，右侧查看器打开对应文件；当前页进入下一轮上下文。
- [ ] 「先问我」只问关键问题，答完继续原请求，不重复问。
- [ ] 「解题」默认先给提示，用户可要完整答案；变式题题号从 1 开始。
- [ ] 引用原文带页码；没读到原文不假装引用。
- [ ] 右侧查看器可开关、可全屏；页签与宽度跨重启恢复。
- [ ] 不写课程进度、不出现在课程统计、不登记课程素材。
- [ ] `tsc` 双配置 0 错；新增契约脚本；真机走一遍“拖图 → 提示 → 完整解 → 变式 → 错题本”。
